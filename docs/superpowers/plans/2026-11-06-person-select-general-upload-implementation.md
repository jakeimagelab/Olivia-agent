# 사진선택 범용화·지속 업로드 구현 계획

1. 호환 마이그레이션: 이벤트 설정, 공유 선택, 업로드 job/파일 체크포인트와 인덱스/RLS 추가.
2. 타입과 프로젝트 유형별 중립 기본값 도입. 기존 상수는 기존 프로젝트 템플릿 호환용으로 유지.
3. 생성/설정 API와 관리자 UI에 세 설정 추가. 선택 데이터가 있으면 접근 방식 전환 차단.
4. 프로젝트 공유 공개 토큰 API와 고객 화면 분기 구현.
5. 업로드 job API, 전역 Provider, OS 상태 표시줄 구현.
6. 기존 상세 페이지의 로컬 업로드 실행 주체를 Provider로 교체하고 복구/재시도 UI 연결.
7. 단위·라우트 테스트, typecheck/lint/build, 실제 브라우저 데스크톱·모바일 검증.
