# 독립 초상권 동의서 구현 계획

작성일: 2026-10-14
기준 설계: `docs/superpowers/specs/2026-10-14-standalone-portrait-consent-design.md`

## 1. 라우팅과 앱 등록

- `/portrait-consent`의 고객관리 강제 이동을 제거한다.
- `portrait-consent`를 Olivia 네이티브 앱 레지스트리에 등록한다.
- 전체 앱 목록에는 표시하고 기본 Dock에는 추가하지 않는다.
- 과거 저장 창과 즐겨찾기의 `portrait-consent` 식별자는 독립 앱으로 복원한다.
- 공개 서명 경로 `/portrait-consent/[token]`은 그대로 유지한다.

## 2. 관리 API

- 목록 응답에 연결 고객명과 촬영 프로젝트명을 추가한다.
- 생성·수정 시 고객과 촬영 프로젝트의 소유 관계를 검증한다.
- 고객 연결 해제 시 촬영 프로젝트 연결도 함께 해제한다.
- 서명 완료 문서의 본문 수정은 거부하고 고객·프로젝트 연결 변경만 허용한다.
- 기존 토큰 발급, 공개 서명, PDF 흐름은 변경하지 않는다.

## 3. 사용자 화면

- 기존 카드 목록과 작성 모달을 왼쪽 목록·오른쪽 작성/상세 화면으로 교체한다.
- 목록에 검색, 상태 필터, 상대 수정 시각, 고객·프로젝트 연결 정보를 표시한다.
- 오른쪽에서 새 문서 작성, 기존 초안 편집, 서명 링크 생성, 서명 완료 상세와 PDF를 처리한다.
- 고객 검색 후 고객을 선택하고, 그 고객의 촬영 프로젝트를 선택적으로 연결한다.
- 좁은 화면에서는 목록과 작성 화면을 한 번에 하나씩 표시한다.
- 고객관리 내장 화면도 같은 컴포넌트를 사용하되 현재 고객·프로젝트로 목록을 제한한다.

## 4. 검증

- 라우팅, 앱 레지스트리, 저장 창·즐겨찾기 마이그레이션 테스트를 갱신한다.
- 고객·프로젝트 연결 입력과 서명 완료 잠금 규칙의 단위 테스트를 추가한다.
- 타입 검사, 변경 파일 린트, 관련 Vitest, 전체 Vitest, 프로덕션 빌드를 실행한다.
- 실제 브라우저에서 넓은 폭과 좁은 폭 화면을 확인한다.
- Supabase 마이그레이션 파일이 추가되지 않았는지 확인한다.
