# 견적서 한글 타이포그래피 구현 계획

1. 병원명 길이를 표시용 크기 단계로 변환하는 작은 순수 함수를 추가하고 경계값 테스트를 작성한다.
2. 견적서 브랜드 레일을 180px로 확장하고 병원명에 한 줄 표시 및 길이별 크기 클래스를 적용한다.
3. 견적서 루트에 로컬 NanumSquare를 우선 적용하고 고정 높이 정보·표·합계 영역의 행간과 중앙 정렬을 정규화한다.
4. 단위 테스트, 타입 검사, 린트, 프로덕션 빌드를 실행한다.
5. 긴 병원명이 포함된 1123×794 견적서를 브라우저에서 확인하고 스크린샷으로 줄바꿈과 세로 정렬을 검증한다.
6. 변경 사항을 커밋하고 `main`에 푸시한 뒤 배포 상태를 확인한다.
