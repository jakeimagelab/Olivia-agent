# 고객 문서 작업공간 구현 계획

1. Desktop 문서 context 복원과 콘티 무대상 보존 버그를 먼저 차단한다.
2. 승인 대기·고객 목록 API와 승인 연결 API를 추가한다.
3. Main/Case/Work 화면과 고객 전용 채팅 패널을 Olivia 밝은 UI 규칙으로 구현한다.
4. 고객 전용 대화 migration, 조회/실행 API, 고정 도구 목록과 clientId 강제 주입을 구현한다.
5. 일정 도구 선택·빈 메모 검증·WorkflowBar·입구 링크 버그를 수정한다.
6. 단위 테스트, 타입 검사, 린트, 브라우저 검증을 실행하고 승인 대기 실제 건수를 확인한다.
