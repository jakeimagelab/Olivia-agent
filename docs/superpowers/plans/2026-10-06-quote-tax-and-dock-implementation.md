# 견적서 부가세·번호와 Dock 구현 계획

## 범위

- 견적서에 `부가세 별도`(기존 기본값), `부가세 제외`, `부가세 포함`을 선택하는 하나의 제어를 추가한다.
- 포토클리닉은 `PCQ-YYYYMMDD-0002`, 제이크이미지연구소는 `JKQ-YYYYMMDD-0002`부터 순번을 사용한다.
- Olivia OS Dock을 `전체 앱 → 캘린더 → 고객관리 → 문서함 → 사진작업실 → 영상작업실 → 메모 → 채팅 → 바탕화면 → 휴지통` 순서로 만든다. 리뷰콘텐츠는 Dock에서만 제거한다.

## 구현 순서

1. `QuoteTaxMode`와 순번 생성 유틸을 추가한다. 기존 저장본에 값이 없으면 `separate`로 읽는다. 포함세는 최종합계에서 공급가와 VAT를 역산하며, 제외세는 VAT를 0으로 둔다.
2. `computeQuoteTotals`를 유일한 계산기로 유지한 채 tax mode를 입력으로 받아 UI, 채팅 카드, 요청 파서, 수정 서비스, 문서 데이터가 같은 결과를 쓰게 한다.
3. QuoteBuilder의 할인 다음에 부가세 방식 버튼을 한 묶음으로 배치한다. 문서/PDF/XLSX의 VAT 라벨도 방식에 따라 `부가세(10%)`, `부가세 제외`, `부가세 포함(10%)`으로 표시한다.
4. 새 tax mode를 `form_state`에 저장하고 행/문서 복원 경로에 전파한다. DB 테이블 열이나 Supabase 마이그레이션은 추가하지 않는다.
5. `/api/quotes`의 번호 조회와 Olivia 채팅 CRUD 생성 모두 브랜드별 새 prefix 및 0002 시작 규칙을 사용한다. 기존 번호는 변경하지 않는다.
6. App Registry와 Dock 렌더링을 분리해, 고정 앱과 유틸리티 버튼을 사용자가 요청한 단일 순서로 렌더한다.
7. 계산·번호·Dock 레지스트리 회귀 테스트를 추가하고 typecheck, 관련 Vitest, lint를 실행한다.

## 검증 기준

- 공급가 1,800,000원: 별도 = 1,980,000원, 제외 = 1,800,000원, 포함 = 공급가 1,636,364원 / VAT 163,636원 / 합계 1,800,000원.
- 각 브랜드의 오늘 첫 생성 번호는 `0002`이며, 해당 접두사의 최고 순번 다음 번호를 사용한다.
- 기존 `PC-`, `JI-`, `Q-` 번호와 tax mode 없는 견적서는 읽기·출력이 유지된다.
- Dock에는 리뷰콘텐츠가 없고 영상작업실이 사진작업실 다음에 있다.
