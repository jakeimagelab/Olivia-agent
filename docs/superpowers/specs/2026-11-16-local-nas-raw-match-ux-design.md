# 로컬 셀렉 → NAS RAW 매칭 UX 보완 설계

## 목표

노트북 Olivia Bridge에서 별점·컬러·작업 대상으로 고른 JPG를 Mac Studio의 NAS RAW와 연결할 때, 사용자가 로컬 탐색 실패를 먼저 겪지 않고 실행 위치를 바로 선택할 수 있게 한다. 기존 파일명+촬영시각 검증, RAW 원본 보호, `Selected_RAW` 복사 규칙은 변경하지 않는다.

## 현재 문제

- `NAS 촬영 폴더 선택`은 로컬 RAW 자동 탐색이 실패한 뒤에만 나타난다. 정상적인 NAS 작업이 실패 복구처럼 보인다.
- 같은 로컬 JPG 폴더와 NAS 촬영 폴더를 반복해서 연결해도 매번 NAS 폴더를 다시 골라야 한다.
- 실행 전에 셀렉 장수와 결과 위치는 보이지만, 로컬 JPG와 NAS JPG/XMP가 유지된다는 안전 범위를 한눈에 확인하기 어렵다.
- 완료 후 Finder는 Mac Studio에서 열리므로 노트북 사용자는 결과 위치를 바로 확인하기 어렵다.

## 검토한 접근

### 1. 현재 흐름 유지

로컬 탐색 실패 뒤 NAS 버튼을 노출한다. 코드 변경은 가장 작지만 실패가 정상 단계가 되는 문제가 남으므로 사용하지 않는다.

### 2. 실행 위치를 처음부터 선택하고 이전 연결을 기억 — 채택

RAW 매칭 진입 즉시 `이 기기에서 찾기`와 `NAS에서 찾기`를 같은 단계에 제공한다. 이전 NAS 연결이 있으면 해당 폴더를 기본 선택하되 자동 실행하지 않고 사용자가 대상과 위치를 확인한 뒤 실행한다. 안전성과 반복 작업 속도를 함께 지킬 수 있다.

### 3. 모든 경로를 자동 추론해 즉시 실행

클릭 수는 가장 적지만 이름이 같은 촬영 폴더나 재마운트된 NAS에서 잘못된 폴더를 고를 위험이 있다. 실행 전 확인 원칙에 맞지 않아 사용하지 않는다.

## 승인된 화면 흐름

1. Bridge에서 별점·컬러 또는 작업 대상을 고른다.
2. `M` 또는 `RAW 매칭`으로 진입한다.
3. 첫 화면에서 다음을 바로 보여준다.
   - `작업 대상 N장`
   - 실행 위치: `이 기기에서 찾기` / `NAS에서 찾기`
   - Mac Studio 연결 상태와 사용할 수 없는 이유
4. NAS를 선택하면 기존 NAS 폴더 선택기를 열고 실제 촬영 폴더를 고른다.
5. 선택한 로컬 Bridge 폴더별로 마지막 NAS 촬영 폴더를 기억한다.
6. 기억된 연결이 있으면 다음 진입부터 해당 NAS 폴더를 미리 표시하고 `변경`을 제공한다.
7. 실행 전 요약에서 다음을 확인한다.
   - 확정 셀렉 장수
   - 선택한 NAS 촬영 폴더
   - 결과 위치 `<촬영 폴더>/Selected_RAW`
   - `RAW만 복사 · 로컬 JPG와 NAS JPG/XMP는 변경하지 않음`
8. 화면의 유일한 채운 버튼 `RAW 매칭 실행 (N장)`으로 실행한다.
9. 완료 결과에서 새로 복사·이미 있음·확인 필요 장수와 NAS 결과 경로를 표시한다.

## UI 원칙

- 기존 중성 다크 RAW 매칭 패널과 공통 작업실 셸을 유지한다.
- 새로운 탭은 만들지 않는다.
- 실행 위치 선택과 폴더 변경은 저채도 외곽선 보조 버튼으로 둔다.
- 채운 민트 주 실행 버튼은 `RAW 매칭 실행` 하나만 둔다.
- Mac Studio가 꺼졌거나 셀렉이 0장이면 버튼 옆에 다음 행동을 한 줄로 표시한다.
- 자동 탐색 상태, 원격 작업 진행률, 실패, 완료는 기존 상태 영역 한곳에서 이어서 보여준다.
- 실패를 거쳐야만 NAS 선택지가 나타나는 조건을 제거한다.

## 연결 기억

- DB 변경 없이 브라우저 `localStorage`를 사용한다.
- 키는 현재 로컬 Bridge 폴더 식별자를 포함한다.
  - 로컬 폴더: breadcrumb 이름을 NFC 정규화해 `/`로 연결한 값
  - 값: 기존 `RemoteNasSelection`에 필요한 NAS 선택 정보
- 읽기·쓰기는 `try/catch`로 감싸 저장소가 차단돼도 RAW 매칭을 사용할 수 있게 한다.
- 기억된 NAS 선택은 기본값일 뿐 자동 실행 권한이 아니다.
- 기억한 폴더가 사라졌으면 실행 시 기존 워커 검증 오류를 표시하고 `NAS 폴더 변경`을 제공한다.

## 데이터와 안전성

- 브라우저는 기존과 동일하게 선택 JPG의 파일명, 상대 경로 힌트, 크기, EXIF 촬영시각과 NAS 폴더 식별자만 전달한다.
- 사진 파일 본문은 Vercel로 보내지 않는다.
- Mac Studio는 파일명과 촬영시각 ±2초가 모두 맞는 RAW만 확정한다.
- RAW 원본은 수정·이동하지 않는다.
- 결과는 선택한 NAS 촬영 폴더의 `Selected_RAW`에 속성을 보존해 복사한다.
- 로컬 JPG와 NAS JPG/XMP는 이동·수정하지 않는다.
- 기존 로컬 RAW 매칭과 NAS Bridge RAW 매칭 동작은 유지한다.

## 컴포넌트 경계

- `PhotoRawMatchWorkspace`: 실행 위치 선택, NAS 선택 복원·저장, 로컬/NAS 화면 전환만 담당한다.
- `SelectMatchRawFolderView`: 로컬 자동 탐색과 무관하게 NAS 선택 동작을 항상 노출한다.
- `RemoteBridgeRawMatchWorkspace`: 실행 전 요약, 원격 작업 생성·폴링, 결과 경로 표시를 담당한다.
- 순수 저장 키·직렬화 함수는 `lib/selectMatch/`에 두어 UI와 분리하고 단위 테스트한다.
- 워커의 매칭·복사 엔진은 변경하지 않는다.

## 오류 처리

- 워커 오프라인: `Mac Studio가 꺼져 있어요. 켠 뒤 다시 시도해 주세요.`
- 셀렉 없음: `Bridge에서 매칭할 사진을 먼저 골라 주세요.`
- 기억한 NAS 폴더 미발견: 워커가 확인한 후보를 기존 실패 박스에 표시하고 `NAS 폴더 변경`을 제공한다.
- 촬영시각 없음·불일치·후보 여러 개: 복사하지 않고 `확인 필요`로 집계한다.
- localStorage 실패: 저장만 생략하고 현재 선택으로 실행한다.

## 검증

- 로컬 RAW 자동 탐색이 진행 중이거나 실패 전이어도 `NAS에서 찾기`를 선택할 수 있다.
- 같은 로컬 Bridge 폴더로 다시 진입하면 마지막 NAS 촬영 폴더가 복원된다.
- 다른 로컬 Bridge 폴더에는 연결 정보가 섞이지 않는다.
- localStorage 접근이 실패해도 NAS 폴더를 선택하고 실행할 수 있다.
- 실행 화면에 작업 대상 수, NAS 폴더, `Selected_RAW` 결과 위치, 변경하지 않는 파일 범위가 보인다.
- Mac Studio 오프라인과 셀렉 0장 상태에서 비활성 이유가 보인다.
- 기존 파일명+촬영시각 매칭 테스트와 로컬/NAS RAW 매칭 회귀 테스트가 통과한다.
- `npx tsc --noEmit`, 관련 Vitest, 넓은 폭·좁은 폭 화면 검증을 수행한다.

## 범위 밖

- RAW 매칭 기준 변경
- RAW/JPG/XMP 파일 처리 방식 변경
- DB 마이그레이션
- NAS 폴더를 사용자 확인 없이 자동 실행하는 기능
- Mac Studio Finder 창을 노트북에 원격 표시하는 기능
