# Olivia Voice 모바일 인터뷰 UI 설계

## 범위

이 작업은 `mobileShell === true`인 Olivia Voice 인터뷰 화면의 정보 구조와 레이아웃만 바꾼다. 준비 API, Version Snapshot, PDF, 녹음, 청크 업로드, 복구, 전사, 결과 데이터는 변경하지 않는다.

## 구성

`VoiceInterviewHub`은 기존의 조회·저장·Ready·재정렬 콜백을 소유한다. 모바일 전용 표현은 두 컴포넌트로 분리한다.

- `MobileInterviewStandby`: 인터뷰 모드 첫 화면
- `MobileInterviewPreparation`: 정보, 질문 선택, 순서 확인의 3단계 마법사

데스크톱과 태블릿은 기존 `VoiceInterviewHub` 레이아웃을 계속 사용한다.

## 모바일 첫 화면

상단은 `← 일반 녹음 / 인터뷰 모드 / 새로고침` 3열, 52px 높이로 고정한다. Hero와 Snapshot 설명은 모바일에서 렌더하지 않는다. 바로 아래에 주황색 전체폭 `새 인터뷰 준비` 버튼을 둔다.

준비 완료 항목은 한 줄형 카드로 표시한다. 카드 본문은 준비 상태, 병원명, 원장명·날짜, 질문 수와 이동 표시만 보이며 카드를 누르면 질문 확인으로 간다. 인터뷰 시작은 작은 primary 버튼으로 유지한다. 빈 상태는 한 줄 문장으로만 보인다. 초안·완료 기록은 52~58px 높이의 목록 행으로 표시한다.

## 3단계 준비 흐름

### 1. 정보 입력

상단에 `1 / 3`, `인터뷰 정보`를 표시한다. 고객, 병원명, 인터뷰 대상, 예정일만 보여준다. 입력 높이는 42~44px, 카드 여백은 14~16px다. 하단 고정 버튼은 `다음: 질문 선택`이다.

### 2. 질문 선택

상단에 `2 / 3`, `질문 선택`을 표시한다. 화면의 대부분을 질문 목록에 쓴다. 외부 카드 테두리는 없애고 섹션 accordion만 유지한다. 선택한 질문 수와 `선택 질문 확인` 버튼은 Dock 위의 고정 action bar에 둔다. 선택 중에는 정보 요약과 `정보 수정`만 보이고, 질문 선택 시 정보는 자동으로 접힌다.

### 3. 순서 확인

상단에 `3 / 3`, `선택 질문 확인`을 표시한다. 선택 질문은 목록 행으로 나타내고 기존 위·아래 순서 변경을 재사용한다. 하단에는 `질문 다시 선택`과 `준비 완료`를 둔다.

## 스크롤과 안전 영역

`MobileVoice`의 외부 body는 현재처럼 overflow를 소유한다. `mobileInterviewFrame`만 별도 세로 스크롤을 갖고 Dock 높이와 선택 bar 높이를 포함한 하단 여백을 확보한다. 35번째 질문도 고정 bar와 Dock 뒤에 가려지지 않아야 한다.

## Ready 화면

모바일 Ready 화면에는 병원명, 원장명, 질문 수, PDF 생성 완료를 표시한다. PDF 보기/다운로드는 한 행, `인터뷰 시작`은 별도의 전체폭 CTA로 둔다.

## 검증

- `mobileShell`에서 Hero·Snapshot 설명이 렌더되지 않는다.
- 새 인터뷰 준비에서 1/3 → 2/3 → 3/3 이동, 질문 수, 순서 변경, 기존 Ready API 호출을 테스트한다.
- iPhone 세로 viewport에서 스크롤·Dock·선택 bar 겹침을 브라우저로 확인한다.
- 데스크톱과 태블릿은 기존 레이아웃을 유지한다.
