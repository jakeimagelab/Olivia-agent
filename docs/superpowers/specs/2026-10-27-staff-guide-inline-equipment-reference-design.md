# 스텝 가이드 장비 사진·체크 통합 설계

작성일: 2026-10-27

## 목표

기존 스텝 가이드에서 `장비 사진`과 `챙길 장비`가 떨어져 있어 같은 장비를 두 번 찾아보는 문제를 없앤다. 사용자가 선택한 촬영 조건에 맞는 장비 사진과 체크 항목을 한 카드 안에서 바로 확인하고 체크할 수 있게 한다.

## 화면 구조

- 별도 `장비 사진` 섹션과 이전·다음 슬라이더를 제거한다.
- `챙길 장비` 섹션을 하나의 통합 섹션으로 유지한다.
- 통합 섹션 상단에는 기존 10개 장비 카테고리 선택 칩을 둔다.
- 선택한 카테고리의 안내 이미지를 보여주고, 같은 카드 바로 아래에 오늘 챙길 해당 카테고리 장비 체크 항목을 표시한다.
- 오늘 촬영 조건에 포함되지 않은 카테고리는 `오늘 챙길 장비 없음`을 표시하되 이미지 안내는 계속 볼 수 있게 한다.
- 카테고리 칩의 순서와 장비 이미지 원본은 그대로 유지한다.
- 통합 뒤의 섹션 번호는 `헷갈리기 쉬운 것` 6, `전체 장비 목록` 7로 당긴다.

## 카테고리 연결

- 카메라 → `CAMERA`
- 렌즈 → `LENS`
- 조명 → `LIGHT`
- A스탠드 → `STAND`
- 삼각대·슬라이더 → `TRIPOD`, `SLIDER`
- 짐벌 → `GIMBAL`
- 배경세트 → 별도 장비 행 없음
- 동조기 → `TRIGGER`
- 배터리 → `BATTERY`
- 저장장치·기타 → `STORAGE`, `ETC`

장비 체크는 기존 `getPackingList()` 결과만 사용한다. 규칙에 없는 장비를 새로 추천하거나 선택 상태에 추가하지 않는다.

## 동작 보존

- 촬영 종류·영상·프로필 형태 선택 동작을 유지한다.
- 장비 체크 상태는 기존 `pc-staff-guide-v1` localStorage 키를 그대로 사용한다.
- 체크 초기화, 카메라 역할, 촬영 종류별 세팅, 전체 장비 목록을 변경하지 않는다.
- 장비 DB, API, 공개 `/staff-guide`, Olivia OS 창 등록과 권한을 변경하지 않는다.

## 반응형·접근성

- 560px 창과 390px 모바일에서 카드 안에 가로 스크롤이 생기지 않게 한다.
- 카테고리 칩 줄만 기존처럼 가로 스크롤을 허용한다.
- 안내 이미지는 원본 비율을 유지하고 카드 너비에 맞춘다.
- 카테고리 버튼은 `aria-pressed`를 유지하고, 체크 항목은 기존 키보드 포커스와 레이블 연결을 유지한다.
- 새 채운 실행 버튼이나 새로운 탭 단계를 만들지 않는다.

## 검증

- 카테고리를 바꾸면 이미지와 체크 항목이 함께 바뀌는지 확인한다.
- 기본값과 영상 포함 조건에서 짐벌 등 동적 체크 항목이 맞게 나타나는지 확인한다.
- 체크 후 새로고침 유지와 체크 초기화를 확인한다.
- 390px 공개 페이지와 560px Olivia OS 창에서 잘림·가로 스크롤을 확인한다.
- `npm run typecheck`, `npm run lint`, 관련 테스트를 실행한다.
