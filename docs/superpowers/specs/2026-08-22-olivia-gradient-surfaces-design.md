# Olivia 그라데이션 표면 UI 디자인

## 목표

홈 채팅창과 전체기능 카드를 공식 브랜드 컬러인 딥그린 `#155855`와 오렌지 `#E85D2C`만으로 연결한다. 채팅은 살아 있는 상태 표현을 제공하고, 기능 카드는 같은 시각 언어를 정적으로 사용한다. 기존 기능, 데이터, 아이콘, 라우팅, 카드 내부 구조는 유지한다.

## 현재 구현과 보완점

- 홈 채팅은 실제 `isStreaming`, 포커스, 입력값으로 `idle`, `typing`, `thinking` 상태를 이미 계산한다.
- `--gb-green`, `--gb-orange`, `--gb-ring-vivid`, `--gb-ring-quiet` 공통 토큰이 존재한다.
- 전체기능 페이지는 실제 데이터 개수를 사용하는 `전체 / 관리자 대시보드 / 고객관리 CRM / AI Assistant` 탭을 이미 사용한다.
- 현재 thinking 종료 시 단일 애니메이션의 duration이 즉시 바뀌어 감속이 다소 급하다.
- 모바일 예외 CSS가 전체기능 카드의 화이트 배경과 그라데이션 테두리를 제거한다.
- 사용되지 않는 과거 민트·블루·퍼플 기반 채팅 그라데이션 토큰이 남아 있다.

## 선택한 구현

### 공통 토큰

- 기존 `--gb-green`, `--gb-orange`를 단일 색상 원천으로 유지한다.
- 채팅용 고강도 링과 카드용 저강도 링은 같은 두 색을 사용하고 opacity만 다르게 한다.
- 사용되지 않는 과거 다색 채팅 테두리 토큰을 제거한다.
- `@property --gb-angle`과 정적 fallback을 유지한다.

### 홈 채팅

- 채팅 DOM과 기능은 변경하지 않는다.
- 외곽 링과 glow는 `pointer-events: none`인 가상 요소로 유지한다.
- idle 레이어는 10초 안팎으로 계속 천천히 회전한다.
- typing/thinking 레이어는 별도 가상 레이어로 겹쳐 실제 상태에 따라 opacity가 전환된다.
- typing은 idle보다 약간 선명하고 8초 안팎으로 움직인다.
- thinking은 4.2초 안팎으로 움직이며 glow가 조금 더 선명해진다.
- thinking 종료 시 빠른 레이어를 500ms 안팎으로 fade-out하고 idle 레이어가 그대로 남도록 해 속도가 갑자기 꺾이는 느낌을 줄인다.
- 실제 상태 외의 가짜 타이머나 프레임별 React 상태 업데이트는 추가하지 않는다.
- `prefers-reduced-motion`에서는 모든 링 회전을 중단하고 정적 그라데이션만 표시한다.

### 전체기능 카드

- 기존 `admin-menu-card`, 아이콘, 텍스트, 배지, 링크 구조를 그대로 사용한다.
- 카드 표면은 데스크톱·태블릿·모바일 모두 화이트로 유지한다.
- 기본 링은 `--gb-ring-quiet`을 사용하며 애니메이션하지 않는다.
- hover/focus-visible에서 opacity와 그림자만 강화하고 카드는 최대 1px 위로 이동한다.
- 아이콘과 텍스트에는 별도 이동 애니메이션을 추가하지 않는다.
- 기존 접근성 focus 표시를 보존하고 링 가상 요소가 클릭을 막지 않게 한다.
- 모바일의 4열 그리드와 카드 내부 정보 축약 규칙은 유지하되, 투명 배경/무테두리 예외만 제거한다.

### 카테고리 필터

- 현재 `ToolCategoryTabs`를 그대로 사용한다.
- 탭 목록과 개수는 `groupToolsByCategory(filteredTools)` 및 실제 검색 결과에서 계산한다.
- 필터는 로컬 상태와 `data-active-tab`으로 즉시 반영하며 새로고침이나 라우팅을 발생시키지 않는다.
- 기능 순서와 분류는 `ALL_TOOLS`를 그대로 따른다.

## 성능과 접근성

- 애니메이션은 CSS custom property, transform, opacity만 사용한다.
- React의 매 프레임 렌더링과 `requestAnimationFrame` 상태 갱신을 추가하지 않는다.
- blur는 홈 채팅의 단일 glow 레이어에만 제한한다.
- 카드 목록에는 지속 애니메이션이나 blur를 적용하지 않는다.
- `prefers-reduced-motion`에서 정적 링과 기존 focus-visible 상태를 유지한다.
