# 견적서 직접 금액 수정 반영 설계

## 문제

채팅으로 만든 견적서는 `fixedTotal`과 `itemPricesHidden`을 저장할 수 있다. 이후 사용자가 견적 편집 화면에서 사용자 항목을 추가하거나 금액을 바꿔도, 기존 `fixedTotal`이 새 합계를 다시 상쇄하고 항목 금액도 숨겨져 수정이 반영되지 않은 것처럼 보인다.

## 동작

- 채팅으로 생성된 견적을 처음 열었을 때의 총액 고정과 금액 숨김은 그대로 유지한다.
- 사용자가 사용자 항목의 금액 칸을 직접 수정하는 순간 `fixedTotal`을 `null`로, `itemPricesHidden`을 `false`로 바꾼다.
- 금액을 입력하거나 지우는 동작 모두 직접 수정으로 본다. 항목명·설명 수정만으로는 두 설정을 바꾸지 않는다.
- 이후 합계 계산, 할인, 부가세, 저장, 다시 열기는 기존 경로를 그대로 사용한다.

## 구현 범위

- 직접 금액 편집인지 판정하고 잠금 상태를 해제하는 작은 순수 함수를 견적 라이브러리에 둔다.
- `QuoteBuilder`의 사용자 항목 금액 변경 처리에서 해당 함수를 적용한다.
- 자동 저장 의존성에 `itemPricesHidden`을 포함해 해제 상태가 저장되도록 한다.
- 데이터 구조와 API 형식은 변경하지 않는다.

## 검증

- 금액 수정은 총액 고정과 금액 숨김을 해제한다.
- 항목명·설명 수정은 기존 설정을 유지한다.
- 채팅 견적에 사용자 항목 금액을 입력하면 합계가 즉시 증가한다.
- 저장 후 다시 열어도 입력 금액, 새 합계, 금액 표시 상태가 유지된다.
