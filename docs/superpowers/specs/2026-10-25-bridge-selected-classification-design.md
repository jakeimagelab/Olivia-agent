# Bridge 선택 사진만 분류하는 동작 수정 설계

작성일: 2026-10-25

## 문제

Bridge에서 일부 JPG만 선택해도 `사진 분류`의 Scene 계획은 현재 폴더 전체 JPG 분석 결과로 생성된다. 이 때문에 사용자가 선택하지 않은 사진도 분류 검토 화면에 나타난다.

## 결정

- Bridge 분류 계획의 입력은 Olivia의 선택과 Adobe Bridge XMP 별점 선택의 합집합만 사용한다.
- Adobe Bridge에서 별점 1~5를 준 JPG를 선택된 사진으로 본다. 일시적인 Content 패널 포커스/선택 테두리는 파일 메타데이터가 아니므로 연동 입력으로 사용하지 않는다.
- XMP 별점은 폴더를 열 때, 앱 창이 다시 포커스될 때, 사진 분류 창을 열 때 다시 확인한다.
- 선택된 파일은 기존 전체 폴더 분석에서 얻은 촬영 시각과 시각 특징을 재사용한다.
- 선택 파일만 촬영 시각순으로 유지하고, 인접한 선택 파일 사이의 Scene 경계를 다시 계산한다.
- Scene 검토 창의 카드, JPG 수, 경계 확인 수는 선택된 사진 기준으로 표시한다.
- 두 선택 출처를 합친 JPG가 0장이면 계획 적용 버튼을 비활성화하고 `Olivia 또는 Adobe Bridge에서 분류할 JPG를 선택해 주세요.`라고 안내한다.
- 분류 화면은 계획에 포함된 JPG만 Scene으로 표시한다. 폴더에 있는 다른 JPG는 계획 유효성 검사를 방해하지 않지만, 계획에 포함된 파일이 삭제되거나 변경되면 적용을 거부한다.

## 보존 범위

- Bridge의 폴더 탐색, 사진 선택, 별점, 레이블, 제외 표시를 바꾸지 않는다.
- Olivia 선택은 기존 공유 실행 컨텍스트를 통해 내부 사진 도구와 계속 양방향 동기화한다.
- Adobe Bridge 메타데이터는 읽기만 하며, 사용자의 JPG/XMP 파일을 자동 수정하지 않는다.
- 전체 폴더 사전 분석과 특징 캐시는 유지한다.
- 진료과 자동 판별, Scene 편집, RAW 수집, 최종 파일 정리 로직은 유지한다.
- 새 탭이나 새 색, 새 주요 버튼을 추가하지 않는다.
- 최종 정리 승인 전에는 파일 시스템을 변경하지 않는다.

## 검증

- XMP 사이드카와 JPG 내장 XMP에서 별점 1~5만 선택으로 읽는지 테스트한다.
- Olivia 선택과 Adobe Bridge 선택의 합집합만 분석에 포함되고 Scene 범위를 모두 덮는지 단위 테스트한다.
- 계획 검증이 폴더의 미선택 JPG는 허용하고, 선택 파일의 누락·변경은 거부하는지 테스트한다.
- Bridge 검토 창이 선택 기준 분석과 0장 안내를 사용하는지 회귀 테스트한다.
- 관련 테스트, 타입 검사, 린트, 빌드와 넓은/좁은 화면을 확인한다.
