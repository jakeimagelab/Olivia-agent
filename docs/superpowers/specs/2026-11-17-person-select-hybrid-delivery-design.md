# 개인별·공동 셀렉 보정본 하이브리드 전달 설계

## 결정

- 고객별 최종 보정본이 50장 이하이면 고화질 원본과 2000px 미리보기를 비공개 Supabase Storage에 저장한다.
- 51장 이상이면 2000px 미리보기만 Storage에 저장하고, 고화질 원본은 Mac Studio가 허용된 NAS 경로에서 읽어 ZIP으로 준비한다.
- 공동 셀렉은 프로젝트 전체 보정본을 하나의 전달 묶음으로 센다. 개인별 셀렉은 사람별 보정본 수를 센다.
- 검토, 수정 요청, 최종 확인, 보관 기간은 전달 방식과 관계없이 동일하다.
- NAS 전달은 최종 확인 이후에만 실행한다. Mac Studio 또는 NAS가 연결되지 않으면 Storage 원본으로 조용히 대체하지 않고 정확한 오류를 보여준다.

## 데이터

`person_select_delivery_versions`에 NAS 원본을 다시 찾을 수 있는 허용 루트 기준 가상 경로를 저장한다. 51장 이상 묶음은 `storage_path_original`을 비워 원본 Storage 업로드를 생략한다. 미리보기 경로는 기존처럼 필수다.

기존 데이터는 `storage_path_original`을 그대로 사용한다. 과거에 올린 51장 이상 묶음도 고객 화면에서는 NAS ZIP 전달을 사용하되, NAS 가상 경로가 없는 이전 버전만 워커가 비공개 Storage 원본을 읽어 묶는다.

## 다운로드 흐름

1. 고객이 모든 보정본을 확인하고 최종 확인한다.
2. 50장 이하는 기존 서명 URL과 브라우저 ZIP 흐름을 사용한다.
3. 51장 이상은 전용 원격 작업 `PERSON_SELECT_DELIVERY_DOWNLOAD`을 생성한다.
4. Mac Studio가 현재 버전의 NAS 가상 경로를 허용 루트 안에서 해석하고 ZIP을 만든다.
5. ZIP만 `person-select-downloads` 비공개 버킷에 임시 업로드한다.
6. 고객에게 10분짜리 서명 URL을 발급한다. 원본 NAS 절대경로는 응답에 포함하지 않는다.

## 안전 규칙

- 원본 NAS 파일은 읽기만 하고 수정·이동하지 않는다.
- 가상 경로는 `OLIVIA_PERSON_SELECT_ROOTS` 허용 루트 안에서만 해석한다.
- 보정본 최종 확인 전에는 다운로드 작업이나 원본 서명 URL을 발급하지 않는다.
- 원격 작업 조회 시 현재 로그인한 사람 또는 공동 검토자와 payload 소유권을 다시 비교한다.
- NAS/워커 오류 때는 미리보기만 유지하고 고객에게 재시도 안내를 표시한다.

## UI

- 관리자 보정본 올리기 안내에 자동 전달 기준만 추가한다. 새 탭이나 별도 주 버튼은 만들지 않는다.
- 고객 하단 바는 50장 이하에서 기존 `한 장씩 저장 / 전체 받기`, 51장 이상에서 `NAS로 전체 받기` 하나를 주 실행으로 보여준다.
- NAS ZIP을 만드는 동안 장수 기반 진행 상태를 같은 하단 상태 문구에 표시한다.
