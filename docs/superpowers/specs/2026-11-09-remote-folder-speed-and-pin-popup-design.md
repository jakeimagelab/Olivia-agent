# 원격 폴더 탐색 속도 및 비밀번호 목록 팝업 설계

작성일: 2026-11-09  
대상: Olivia 원격 NAS 폴더 선택기, 개인별 사진선택 관리자

## 목표

1. Mac Studio와 NAS를 사용하는 원격 폴더 선택기의 반복 탐색 대기 시간을 줄인다.
2. 개인별 사진선택 비밀번호 목록을 CSV를 내려받지 않아도 관리자 앱 안에서 확인할 수 있게 한다.
3. 관리자 인원 매칭 첫 화면에서 잘리는 대표 사진 대신 폴더를 명확히 표시한다.
4. 이름 폴더 끝에 붙은 직책은 원본 폴더명과 표시 이름에는 보존하되 로그인 이름에서는 제외한다.
5. 기존 사진 가져오기, PIN, 참가자, CSV 내보내기와 권한 검증을 그대로 보존한다.

## 원격 폴더 탐색

### 현재 병목

폴더를 열 때마다 브라우저가 원격 작업을 생성하고, Mac Studio가 작업을 가져가 NAS를 조회한 뒤 결과를 보고한다. Worker는 유휴 상태에서 5~10초 간격으로 작업을 확인한다. 또한 `folders_only` 요청에서도 각 폴더에 대해 NAS `stat`을 순차 실행한다.

### 변경

- `folders_only` 요청에서는 `Dirent`로 확인된 폴더명과 경로만 반환한다. 수정 시각과 용량을 위한 개별 `stat`은 실행하지 않는다.
- 원격 데이터 소스 인스턴스가 완료된 폴더 결과를 30초 동안 메모리에 보관한다.
  - 캐시 키는 action, 대상 Worker, root/path, `folders_only` 조합으로 구분한다.
  - 캐시가 있으면 새 원격 작업을 만들지 않고 즉시 반환한다.
  - 실패, 취소, 시간 초과 결과는 캐시하지 않는다.
- Worker는 평상시 기존 5~10초 유휴 폴링을 유지한다.
  - 원격 작업을 하나 처리한 뒤 30초 동안만 1초 간격의 대화형 탐색 구간을 사용한다.
  - 대화형 구간이 끝나면 기존 지수형 유휴 간격으로 복귀한다.
  - 항상 1초로 폴링하지 않아 Vercel 호출량 증가를 제한한다.

### 보존 조건

- 절대경로 및 허용 root 검증을 유지한다.
- 파일 목록 조회는 기존 크기·수정일 정보를 유지한다.
- 폴더 선택, 두 번 탭 열기, 검색, 오류 재시도 UI는 변경하지 않는다.
- 사진 파일을 읽거나 변환하지 않는다.

## 비밀번호 목록 팝업

### 데이터 접근

- 기존 관리자 전용 `exports/pins` 경로에 JSON 응답 모드를 추가한다.
- CSV 요청은 기존과 동일한 파일을 반환한다.
- JSON도 기존과 동일하게 관리자 세션을 확인하고 현재 프로젝트의 `person_select_people`만 조회한다.
- 행사 상세의 일반 조회 응답에는 `pin_code`를 추가하지 않는다.

### UI

- 기존 `비밀번호 목록` 링크를 버튼으로 변경한다.
- 버튼을 누를 때만 JSON 목록을 요청하고 중앙 팝업을 연다.
- 팝업은 현재 Olivia 밝은 관리 화면 토큰을 사용하며 다음을 표시한다.
  - 프로젝트명
  - 전체 인원 수
  - 이름
  - 담임반 또는 그룹
  - 비밀번호
- 긴 목록은 팝업 본문에서 독립적으로 스크롤한다.
- 닫기 버튼, 배경 클릭, Escape로 닫을 수 있다.
- 팝업 안에 기존 `CSV 다운로드` 동작을 유지한다.
- 로딩, 빈 목록, 조회 실패 상태를 각각 표시한다.

### 보안과 데이터 보존

- 관리자 인증이 없는 JSON/CSV 요청은 계속 거부한다.
- PIN을 재발급하거나 수정하지 않는다.
- 팝업을 닫을 때 PIN 데이터를 서버에 다시 저장하지 않는다.
- 공용 프로젝트에는 기존처럼 비밀번호 목록 버튼을 표시하지 않는다.

## 인원 매칭 폴더 카드

- 관리자 인원 매칭 첫 화면의 각 사람 카드에서 대표 사진 썸네일을 표시하지 않는다.
- 사진 영역은 Olivia 아이콘 규격의 폴더 아이콘과 중립 배경으로 바꾼다.
- 폴더명, 등록 사진 수, 원본 폴더 정보와 카드 선택 동작은 유지한다.
- 대표 사진 URL을 브라우저가 요청하지 않으므로 얼굴·신체가 잘리는 문제와 첫 화면 이미지 요청을 함께 제거한다.
- 참가자 상세와 실제 사진 확인 화면의 썸네일은 변경하지 않는다.

## 로그인 이름에서 직책 제외

- 원본 폴더명과 `display_name`은 현재 값 그대로 유지한다. 예를 들어 `김정현과장님` 폴더는 관리자 화면에서도 같은 이름으로 보인다.
- 신규 개인 폴더를 가져올 때 로그인 이름만 `김정현`처럼 만든다.
- `과장님`, `부장님`, `대리님`, `대표님`처럼 명시적으로 지원하는 끝 직책만 제거한다. 이름 중간의 같은 문자열이나 단순한 `님`은 제거하지 않는다.
- 기존 참가자는 관리자 팝업의 명시적인 정리 동작으로만 변경한다. 변경 전 현재 로그인 이름과 추천 로그인 이름을 함께 보여준다.
- 직책 제거 결과가 같은 로그인 이름으로 겹치거나, 이름이 비게 되거나, 실제 접속 기록이 있어 안전한 자동 변경을 보장할 수 없으면 일부만 바꾸지 않고 정확한 이유와 대상을 표시한다.
- 사진 소유 관계, PIN, 참가자 ID, 선택·주문·제출 기록은 변경하지 않는다.
- 로그인 입력 정규화 자체는 유지하여 기존 로그인 이름과의 호환을 깨뜨리지 않는다.

## 오류 처리

- 폴더 캐시가 없거나 만료되면 기존 원격 작업 경로를 사용한다.
- Worker/NAS 오류는 캐시된 성공 결과로 영구 은폐하지 않으며, 캐시 만료 뒤 실제 상태를 다시 확인한다.
- 비밀번호 목록 요청 실패 시 팝업 안에 오류와 다시 시도 동작을 제공하고 CSV 다운로드 여부를 거짓으로 성공 표시하지 않는다.

## 검증

- 원격 데이터 소스 테스트
  - 첫 조회는 작업 생성 및 폴링을 수행한다.
  - 같은 경로의 30초 이내 재조회는 캐시를 사용한다.
  - 다른 Worker, action, path, `folders_only` 요청은 캐시가 분리된다.
  - 실패와 중단 요청은 캐시되지 않는다.
- Mac Studio Worker 테스트
  - `folders_only`에서 폴더 목록이 유지되고 파일이 제외된다.
  - 파일 목록 조회의 메타데이터는 유지된다.
  - 유휴 폴링은 기존 최대 10초를 유지한다.
  - 작업 직후 30초 동안만 1초 폴링한 뒤 유휴 간격으로 복귀한다.
- 비밀번호 API 테스트
  - 관리자 JSON 응답과 CSV 응답이 같은 참가자 순서를 사용한다.
  - 비관리자 요청을 거부한다.
  - 직책이 붙은 표시 이름에서 안전한 로그인 이름을 만들고, 중복 추천 이름은 변경을 차단한다.
- UI 동작 테스트
  - 버튼으로 팝업 열기, 로딩, 목록, 실패, 닫기, CSV 다운로드를 확인한다.
  - 공용 프로젝트에서는 버튼과 팝업이 나타나지 않는다.
  - 인원 매칭 카드는 대표 사진 대신 폴더 아이콘을 표시하고 기존 폴더 정보와 클릭 동작을 유지한다.
- `npx tsc --noEmit`과 관련 Vitest를 실행한다.

- 사진 업로드·축소·가져오기 로직 변경
