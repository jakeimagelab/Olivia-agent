# Bridge 빨강 셀렉 필터 설계

## 목표

Olivia Bridge에서 6번 빨강 컬러 라벨 사진만 RAW 매칭 대상으로 고르기 쉽게 만든다.

## 동작

- 왼쪽 `셀렉 보기` 영역에 `빨강 셀렉` 행을 추가한다.
- 행에는 현재 폴더의 6번 빨강 라벨 사진 수를 표시한다.
- 누르면 기존 `⌥⌘6`과 동일한 `{ kind: "color", label: 6 }` 필터를 적용한다.
- 활성 상태에서 다시 누르면 전체 JPG 보기로 돌아간다.
- 필터된 상태에서 기존 `⌘/Ctrl+A` 전체 선택과 `RAW 매칭`을 그대로 사용한다.
- 셀렉 기준이 Adobe인 경우 선택 변경이 차단되는 기존 안내는 유지한다.

## 보존 사항

- 별점 1~5, 컬러 라벨 6~9, 고객 셀렉, Adobe 동기화 데이터는 변경하지 않는다.
- RAW 매칭 입력은 계속 `selectedIds`를 사용한다.
- 단축키, 리뷰, 전체화면, 파일 탐색 UI는 변경하지 않는다.
- 새 색이나 별도 탭을 만들지 않고 기존 필터 행 스타일을 재사용한다.

## 검증

- 빨강 라벨 수가 정확히 표시되는지 확인한다.
- 버튼과 `⌥⌘6`이 같은 필터 결과를 만드는지 확인한다.
- 빨강 필터 → 전체 선택 → RAW 매칭 시 빨강 사진만 전달되는지 테스트한다.
- 다른 라벨과 기존 Bridge 동작의 회귀 테스트를 실행한다.
