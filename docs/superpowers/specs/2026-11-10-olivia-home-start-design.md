# Olivia 재실행 홈 시작 설계

## 목표

- Olivia를 일반 실행, 재실행 또는 새로고침하면 데스크톱·모바일·태블릿 모두 홈에서 시작한다.
- 저장된 데스크톱 작업 창은 삭제하지 않고 백그라운드에 보존한다.
- `oliviaApp=customer`처럼 실제 대상을 명시한 실행 요청은 해당 화면을 연다.
- 이전 고객이나 문서 문맥을 홈 화면의 현재 대상으로 사용하지 않는다.

## 동작

### 데스크톱

저장된 창의 위치와 문맥을 기존 마이그레이션 규칙대로 불러오되 `activeWindowId`는 복원하지 않는다. 따라서 첫 화면은 홈이고, 사용자가 Dock에서 앱을 다시 누르면 보존된 창을 이어서 사용할 수 있다. 명시적 실행 요청은 상태 복원 뒤 해당 앱을 열어 활성화한다.

### 모바일·태블릿

일반 시작 상태는 URL에 남아 있는 이전 화면 값과 무관하게 홈으로 정한다. 첫 마운트에서 이전 탐색용 쿼리를 홈 URL로 교체한다. 명시적 고객 실행 요청은 기존 고객 화면 진입을 유지한다.

## 회귀 방지

- 데스크톱 상태 저장 형식과 기존 창 마이그레이션은 변경하지 않는다.
- 명시적 고객 실행 링크는 유지한다.
- 내부 앱 이동과 뒤로가기는 마운트 이후 기존 탐색 로직을 그대로 사용한다.
- 데스크톱 상태 복원 함수의 기본 동작은 유지하고, OS 셸 시작 호출에서만 홈 시작 옵션을 사용한다.
