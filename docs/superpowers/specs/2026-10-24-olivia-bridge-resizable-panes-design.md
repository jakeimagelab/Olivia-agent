# Olivia Bridge 영역 크기 조절 설계

## 목표

Olivia Bridge의 폴더, 파일 목록, 일반 미리보기 영역을 한 화면 안에서 사용자가 직접 조절한다. 파일 목록은 기본적으로 가장 넓게 두고, 폴더 및 미리보기 영역은 작업 상황에 따라 늘리거나 줄일 수 있게 한다.

## 구조

- 폴더와 파일 목록 사이, 파일 목록과 미리보기 사이에 각각 세로 분할선을 둔다.
- 기본 폭은 폴더 210px, 미리보기 300px이며 파일 목록이 남은 폭을 모두 사용한다.
- 폴더는 150~360px, 미리보기는 240~560px 안에서 조절한다.
- 가운데 파일 목록은 넓은 창에서 420px, 좁은 창에서 320px의 안전 폭을 우선 확보한다.
- 760px 이하의 기존 세로 배치에서는 분할선을 숨긴다.

## 상호작용

- 분할선 드래그는 해당 영역의 CSS 변수만 갱신해 큰 썸네일 그리드를 다시 렌더링하지 않는다.
- 두 분할선은 키보드 화살표로도 24px씩 조절할 수 있다.
- 더블클릭하면 해당 영역이 기본 폭으로 돌아간다.
- 창 크기가 바뀌면 현재 폭을 안전 범위 안으로 자동 보정한다.
- 조절한 폭은 브라우저에 저장해 Bridge를 다시 열어도 복원한다.

## 보존 사항

폴더, 선택 파일, 별점, 제외 표시, 도구 팝업, 전체 화면 미리보기 상태와 동작은 바꾸지 않는다.
