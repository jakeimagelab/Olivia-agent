# 영상작업실 v2 카테고리 개편

## 목표

기존 영상작업실과 다중 Worker 기능을 유지하면서 영상 관련 후반 작업을 한 작업실 안에 정리한다. 제공된 `video-studio-v2.zip`의 두 번째 패치를 기준으로 영상 분류를 사진작업실에서 영상작업실로 이동한다.

## 기준과 병합 원칙

- 현재 `feature/video-studio`의 인터뷰 분석·릴스·웹진 초안·음성 분리와 Mac Studio/MacBook Pro 선택 기능을 기준으로 삼는다.
- ZIP의 첫 번째 패치는 이미 반영된 원본이므로 다시 적용하지 않는다.
- ZIP의 두 번째 패치만 적용하되 충돌 시 기존 코드를 삭제하지 않고 카테고리 개편 부분을 수동 병합한다.
- 영상 인터뷰 분석 로직, 다중 Worker 인증, Worker 설치 코드와 결과 내보내기 로직은 변경하지 않는다.

## 최종 영상작업실 구성

영상작업실 탭은 다음 순서를 사용한다.

1. 인터뷰 분석
2. 릴스
3. 웹진 초안
4. 영상 분류
5. 음성 분리

인터뷰 분석과 음성 분리는 기존처럼 선택한 Mac Studio 또는 MacBook Pro Worker에서 실행한다. 영상 분류는 브라우저의 로컬 파일 기능을 사용하므로 `이 기기에서 작업`으로 실행한다.

## 기존 기능 이동과 호환

- 기존 `app/(photo-studio)/video-sorting/page.tsx`의 실제 영상 분류 UI를 `components/video-studio/VideoSortingWorkspace.tsx`로 이동한다.
- 사진작업실 탭에서 `영상 분류`와 더 이상 사용하지 않는 `4K→FHD 변환` 항목을 제거한다.
- `/video-sorting` 단독 경로는 외부 공유 링크 호환을 위해 유지하고 같은 `VideoSortingWorkspace`를 렌더링한다.
- 영상작업실은 `?tab=sorting`을 통해 영상 분류 탭을 직접 열 수 있다.
- Olivia OS 창에서도 초기 탭 파라미터를 영상작업실에 전달한다.

## 검색과 앱 분류

- `WORKSPACE_GROUPS`에 영상작업실 그룹을 추가한다.
- `영상 분류`, `/video-sorting`과 관련 검색어는 `/video-studio?tab=sorting`으로 연결한다.
- 기존 `영상제작`, `콘티 스튜디오`, `유튜브 편집 콘티`, `B-roll 프롬프트`, `프롬프터`는 촬영 전 기획·생성 기능이므로 별도 앱으로 유지한다.

## UI와 실행 위치

- 기존 Olivia 영상작업실 탭·카드·가이드 디자인을 그대로 사용한다.
- 영상 분류 탭에서는 Worker 선택기를 숨기고 로컬 실행 안내를 표시한다.
- 인터뷰 분석과 음성 분리 탭에서만 기존 Worker 선택기를 표시한다.
- 탭 변경 시 실행 위치 상태가 해당 기능에 맞게 전환되도록 하되 사진작업실의 실행 위치 동작은 변경하지 않는다.

## 검증

1. 영상작업실 탭 5개가 정해진 순서로 표시된다.
2. 영상 분류 탭에서 기존 분류 UI와 동작이 유지된다.
3. 영상 분류는 로컬 실행, 인터뷰 분석·음성 분리는 원격 Worker 실행으로 표시된다.
4. Mac Studio/MacBook Pro 선택과 최근 작업 배지가 유지된다.
5. 사진작업실 탭에서 영상 분류와 4K→FHD 변환이 제거된다.
6. `/video-sorting` 공유 링크가 계속 열린다.
7. 검색과 Olivia 기능 해석기가 영상 분류를 영상작업실로 연결한다.
8. 타입 검사, 관련 Vitest, lint와 build가 통과한다.
