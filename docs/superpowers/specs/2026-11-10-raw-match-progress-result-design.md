# RAW 매칭 진행·완료 화면 간소화 설계

작성일: 2026-11-10

## 목표

RAW 매칭 중에는 진행률을 즉시 이해할 수 있게 퍼센트를 표시하고, 파일별 로그 목록은 숨긴다. 완료 후에는 수량 결과와 `Selected_RAW` 폴더 접근 동작만 제공한다.

## 범위

- 대상: `components/photo-workspace/SelectMatchWorkspace.tsx`
- RAW 검색, 복사·이동, 중단, JPG 및 XMP 보정본 이동 로직은 변경하지 않는다.
- 기존 `N차보정본` 자동 번호 증가는 유지한다. 예를 들어 `1차보정본`이 있으면 다음 기본 폴더명은 `2차보정본`이다.
- 완료 후 열기 대상은 `Selected_RAW`만이다. `N차보정본`은 열기 대상에 포함하지 않는다.

## 진행 화면

- 진행 게이지에 정수 퍼센트를 표시한다.
- 게이지 아래에는 `처리한 장수 / 전체 장수`와 현재 처리 중인 파일명 한 줄만 표시한다.
- 기존 실시간 파일별 처리 로그 목록은 화면에서 제거한다.
- 마지막 파일 처리 후 진행 상태를 명시적으로 전체 장수로 갱신해 정상 완료 시 반드시 `100%`가 되게 한다.
- 기존 `중단` 동작은 유지한다.

## 완료 화면

- `선택 JPG`, `RAW 매칭`, `RAW 누락`, `실패`, JPG·XMP 이동 결과를 수량으로 표시한다.
- 누락·실패 파일명의 펼침 목록은 표시하지 않는다.
- 권한 거부나 JPG 이동 생략처럼 사용자가 알아야 할 결과 안내는 유지한다.
- 보조 동작으로 `Selected_RAW 폴더 열기` 버튼을 제공한다.
- 브라우저 File System Access API의 보안 범위 안에서, 보관한 `Selected_RAW` 디렉터리 핸들을 시작 위치로 운영체제 폴더 선택 창을 연다. API가 없거나 핸들이 유효하지 않으면 정확한 안내를 표시하며 RAW 결과를 변경하지 않는다.
- 기존 `다시 선택`, `처음으로` 동작은 유지한다.

## 상태와 오류 처리

- 생성한 `Selected_RAW` 디렉터리 핸들을 현재 RAW 매칭 세션 상태에만 보관한다.
- 새 매칭을 시작하거나 처음으로 돌아가면 이전 출력 폴더 핸들을 초기화한다.
- 취소된 작업은 완료로 오인하지 않으며, 실제 처리한 수량을 결과로 유지한다.
- 폴더 열기 실패는 파일 처리 성공 여부와 분리해 표시한다.

## UI 원칙

- 기존 RAW 매칭 작업 패널의 중성 다크 톤과 민트 실행색을 유지한다.
- 새로운 탭이나 색상은 추가하지 않는다.
- 채운 주 실행 버튼은 기존 규칙을 유지하고, 폴더 열기는 보조 버튼으로 둔다.
- 파일별 목록을 없애 진행 상태를 한 곳에 모은다.

## 검증

- 진행률 계산: 시작 `0%`, 중간값, 완료 `100%`.
- 정상 완료: 결과 수량과 `Selected_RAW` 열기 버튼 표시.
- 누락·실패 포함 완료: 수량은 정확하고 파일명 목록은 표시하지 않음.
- 중단: 처리한 수량까지만 반영하고 완료로 오인하지 않음.
- 기존 `1차보정본` 존재 시 `2차보정본` 자동 제안 회귀 확인.
- `npx tsc --noEmit`과 관련 Vitest 실행.
