# Olivia OS 홈 Dock 및 오늘 요약 설계

## 목적

- Dock의 `오늘` 앱 진입을 없애고 첫 칸을 언제나 메인 채팅으로 돌아가는 `홈` 동작으로 바꾼다.
- 기존 오늘 화면의 `오늘 일정`, `오늘 할 일`, `최근 작업`은 홈 화면 안에 작은 요약으로 남긴다.
- 메인 채팅과 `내 차례` 목록의 시각적 우선순위는 그대로 유지한다.

## 동작

- Dock의 `홈`은 앱을 여는 버튼이 아니다. 활성 앱이 있으면 전체화면 앱을 숨기고 홈 채팅을 보여준다.
- 이미 홈에 있으면 아무 일도 하지 않는다.
- 기존 `today` 앱 등록과 화면은 과거 링크 및 모든 앱 호환을 위해 유지하되 Dock에서는 제외한다.
- 기존 `toggleShowDesktop` API 이름과 호출부는 유지한다. 활성 앱이 있으면 홈으로, 홈에서 다시 호출하면 직전 앱으로 돌아가는 순서를 명확히 한다.

## 홈의 오늘 요약

- 인사/날짜와 `내 차례` 목록 사이에 한 줄짜리 3열 요약을 둔다.
- 열은 `오늘 일정`, `오늘 할 일`, `최근 작업` 순서다.
- 각 열은 전체 개수와 첫 항목 하나만 표시한다. 데이터가 없으면 `없음`, 로딩 중이면 `불러오는 중`으로 표시한다.
- 일정과 할 일은 누르면 기존 일정 앱으로 이동한다. 최근 작업은 읽기 전용으로 둔다.
- 별도 카드나 새 색을 만들지 않고 홈의 반투명 흰색 계열을 사용한다. 글자 크기는 9.5~10.5px, 굵기는 600 이하로 제한한다.

## 데이터와 성능

- 일정과 할 일은 이미 홈 상위에서 공급하는 `HomeDashboardDataProvider`를 재사용한다.
- 최근 작업은 기존 `/api/admin/recent-activity`를 홈의 다른 요청과 병렬 호출한다.
- 새 API, 새 테이블, 새 전역 상태는 만들지 않는다.

## 검증

- Dock 첫 칸이 `홈`이고 `오늘`이 Dock 목록에 없다.
- 어느 앱에서든 `홈`을 누르면 메인 채팅으로 돌아온다.
- 홈에서 `홈`을 다시 눌러도 직전 앱이 다시 열리지 않는다.
- 일정·할 일·최근 작업이 각 한 줄로 작게 표시되고 홈 입력창과 `내 차례`를 가리지 않는다.
- 기존 `오늘` 앱은 레지스트리와 모든 앱에서 계속 열 수 있다.
