# 고객 Bridge 텍스트 이용 가이드 설계

## 목적

고객이 Bridge 화면 안에서 사진 확인과 셀렉 방법을 바로 이해할 수 있도록 상단 도구 모음에 `이용 가이드` 진입 버튼을 제공한다. 참고 이미지의 정보 구조만 사용하고 이미지 자체는 서비스에 포함하지 않는다.

## 검토한 방식

1. **화면 내 안내 대화상자 — 채택**
   - 현재 작업 위치와 셀렉 상태를 유지한 채 가이드를 확인할 수 있다.
   - 데스크톱과 모바일에서 같은 진입 버튼과 내용을 사용할 수 있다.
2. 별도 가이드 페이지
   - 긴 설명에는 유리하지만 현재 Bridge를 벗어나야 하고 복귀 흐름이 추가된다.
3. 새 브라우저 탭
   - 구현은 단순하지만 모바일 탭 전환과 팝업 차단 가능성이 있어 적합하지 않다.

## 화면과 동작

- 고객 Bridge 상단 도구 모음에 선 아이콘과 `이용 가이드` 라벨을 가진 보조 버튼을 추가한다.
- 버튼을 누르면 밝은 패널의 모달 대화상자를 연다.
- 모달은 다음 방법으로 닫을 수 있다.
  - 우측 상단 닫기 버튼
  - `Escape` 키
  - 모달 바깥 배경 클릭
- 모달 내부 내용만 세로 스크롤하며 Bridge 본문과 선택 상태는 그대로 유지한다.
- 모바일에서는 화면 너비에 맞추고 iOS safe area를 반영한다.
- 최소 터치 영역은 44px로 유지한다.
- 배경 blur는 사용하지 않는다.

## 안내 내용

1. 폴더 탐색과 전체 사진 보기
2. 사진 클릭은 확인/작업 대상 지정이며 최종 셀렉이 아니라는 주의
3. 숫자 `1~5` 별점 셀렉, `0` 해제, `6~9` 컬러 셀렉
4. `Shift`, `Cmd/Ctrl`, 드래그를 이용한 다중 작업 대상 선택
5. 리뷰 진입과 방향키, 제외/복원, 전체화면
6. 사진별 보정 메모
7. 자동 저장과 최종 제출의 차이
8. 프로젝트 대화, 허용된 원본 다운로드, 모바일 사용

## 스타일

- 기존 고객 Bridge의 `headerAction` 계열 보조 버튼을 재사용한다.
- 가이드는 밝은 정보 화면이므로 기존 Olivia 토큰의 밝은 패널, 브랜드 그린, 얇은 경계선을 사용한다.
- 오렌지는 새 버튼에 사용하지 않으며 기존 최종 제출 주 실행을 유지한다.
- 새로운 탭 단계나 카드형 작업 UI를 추가하지 않는다.

## 데이터와 기능 보존

- 고객 별점, 컬러 라벨, 작업 대상, 메모, 채팅, 다운로드, 자동 저장, 제출 API를 변경하지 않는다.
- 관리자 Bridge와 classic 사진선택을 변경하지 않는다.
- 가이드 열기/닫기는 로컬 UI 상태만 사용한다.

## 검증

- 버튼 클릭으로 가이드가 열리고 세 가지 닫기 방식이 작동하는지 확인한다.
- 가이드가 열린 동안 기존 고객 셀렉 데이터가 변경되지 않는지 확인한다.
- 데스크톱과 모바일에서 마지막 안내 항목까지 스크롤 가능한지 확인한다.
- 키보드 단축키가 가이드 뒤의 Bridge에 전달되지 않는지 확인한다.
- TypeScript 검사와 관련 컴포넌트 테스트를 실행한다.
