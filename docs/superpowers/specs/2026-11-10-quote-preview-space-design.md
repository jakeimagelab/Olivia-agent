# 견적서 미리보기 공간 확대 설계

## 목표

데스크톱 견적서 작성 화면에서 사용하지 않는 바깥 여백을 줄이고, 편집 영역의 읽기 가능한 폭은 유지하면서 남는 공간을 실시간 미리보기에 배정한다.

## 범위

- `components/quote/QuoteBuilder.tsx`의 데스크톱 작성 화면 레이아웃만 조정한다.
- 전체 콘텐츠 최대 폭을 1500px에서 1720px로 넓힌다.
- 바깥 좌우 패딩과 편집/미리보기 사이 간격을 줄인다.
- 편집 열은 약 400~420px 범위에서 유지하고 미리보기 열이 나머지 폭을 사용하게 한다.
- Olivia OS 창 안의 견적서와 독립 견적서 페이지에 같은 원칙을 적용한다.

## 보존 사항

- `QuoteDocument`의 1123×794 문서 캔버스와 출력 디자인은 변경하지 않는다.
- PDF, 전체화면 미리보기, 확대/축소 계산과 저장 로직은 변경하지 않는다.
- 모바일의 단일 패널 전환과 좁은 화면 축소 동작은 유지한다.
- 입력 폼, 버튼, 색상, 글꼴, 데이터/API 동작은 변경하지 않는다.

## 검증

- 1440×900과 1920×1080에서 미리보기 문서가 기존보다 크게 표시되는지 확인한다.
- 편집 폼이 잘리거나 가로 스크롤되지 않는지 확인한다.
- 좁은 Olivia OS 창과 모바일에서 기존 전환 동작이 유지되는지 확인한다.
- TypeScript 검사와 관련 테스트를 실행한다.
