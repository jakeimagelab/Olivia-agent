# OliviaOS 공통 UI 디자인 적용 사양

작성일: 2026-10-30  
대상: Olivia-agent-main  
상태: 사용자 최종 확정안

## 목표

기존 Desktop, Window, Dock, 메뉴, 탭, 폼, API와 저장 동작을 유지하면서 OliviaOS의 조작 화면을 하나의 밝고 차분한 업무용 시각 언어로 통일한다. 전체 바탕은 웜화이트, 주요 작업 영역은 연한 그레이그린, 입력·카드·미리보기는 밝은 표면색, 주요 실행은 포토클리닉 오렌지를 사용한다.

## 구현 접근

공통 디자인 토큰을 `app/globals.css`의 기존 `:root` 테마에 추가하고, 기존 토큰에는 호환 별칭을 둔다. 전역 `button` 또는 `svg` 선택자로 색을 강제하지 않는다. 공통 UI 프리미티브와 각 핵심 화면의 의미 있는 클래스가 토큰을 사용하도록 연결한다.

화면마다 유사한 색을 다시 선언하지 않는다. 단, 실제 문서 지면, 인쇄/PDF, 사진·영상 판단 영역처럼 원래 표현을 보존해야 하는 곳에는 새 앱 테마를 상속시키지 않는다.

## 공통 토큰

```css
--ui-bg: #F4F3EF;
--ui-header: #F8F8F4;
--ui-workspace: #E8EBE5;
--ui-surface: #FCFBF8;
--ui-border: #D5DBD3;
--ui-text: #2F3833;
--ui-text-secondary: #626D65;
--ui-brand-green: #155855;
--ui-green-soft: #E2EBE3;
--ui-orange: #E85D2C;
--ui-orange-strong: #C94C22;
--ui-orange-soft: #FBEAE3;
--ui-radius-control: 10px;
--ui-radius-panel: 16px;
--ui-shadow-panel: 0 6px 24px rgba(40, 55, 45, 0.06);
```

기존 `--deep-green`, `--teal`, `--orange`, `--content-bg`, `--panel-bg`, `--ink`, `--muted`, `--line`은 삭제하지 않는다. 새 토큰을 기준으로 값 또는 별칭을 맞춰 기존 호출부가 같은 분위기를 받도록 한다.

## 공통 컴포넌트

### 버튼

- 주 실행: `--ui-orange-strong` 채움, 흰 글자, 화면당 하나.
- 보조: `--ui-surface` 바탕, 오렌지 글자·아이콘·테두리, 호버는 `--ui-orange-soft`.
- 아이콘 실행: 채팅 열기·전송·새 대화와 같은 실행 아이콘만 오렌지.
- 비활성: 중립 테두리와 읽을 수 있는 보조 글자색. opacity만 낮추지 않는다.
- 오류·삭제·성공·연결 상태의 기존 의미색은 보존한다.

### 입력·카드·팝업

- 입력과 카드: `--ui-surface`, `--ui-border`, `--ui-radius-control` 또는 `--ui-radius-panel`.
- 포커스: 오렌지 또는 브랜드 그린 계열의 명확한 링을 표시한다.
- 팝업 뒤 배경에는 새로운 blur 효과를 추가하지 않는다.
- 모든 기존 닫기, 저장, 로딩, 중복 실행 방지 동작을 유지한다.

### 로고

`public/assets/photoclinic-logo.png`와 `public/assets/photoclinic-mark.png`를 재사용한다. 색상, 비율, 투명도를 바꾸지 않고 CSS filter나 마스크를 적용하지 않는다.

## 화면별 적용

### 콘티

- 앱 셸과 큰 편집 영역은 웜화이트·연한 그레이그린 계층으로 정리한다.
- 입력, 표, 미리보기는 밝은 표면색을 쓴다.
- 생성, 저장 등 주 실행은 오렌지로 통일한다.
- 표, 입력 검증, 생성 조건, 공유, 저장 동작은 바꾸지 않는다.
- 실제 콘티 인쇄·공유 지면에는 앱 테마가 번지지 않는다.

### 견적서

- 편집 영역과 도구 영역은 연한 그레이그린, 입력과 세부 카드는 밝은 표면색을 쓴다.
- 저장·다운로드·완료 버튼을 공통 역할 스타일로 맞춘다.
- 실제 견적서 지면, 로고, 브랜드 요소, PDF·인쇄 결과는 그대로 유지한다.

### 일정

- 달력 주변과 도구 영역은 연한 그레이그린, 날짜 칸과 상세 패널은 밝은 표면색을 쓴다.
- 오늘과 선택 날짜는 기존 의미를 유지하며 명확히 구분한다.
- 일정 종류 색상과 데이터 동작은 보존한다.

### 고객관리

- 기존 목록과 상세 정보 구조는 유지한다.
- 페이지 바탕, 목록 표면, 입력, 팝업을 공통 토큰에 연결한다.
- 고객 등록·열기 등 주요 실행만 오렌지를 사용한다.
- 진행률과 상태 의미색은 보존한다.

### 올리비아 채팅

- 배경은 웜화이트, 현재 작업/사용자 말풍선은 연한 그레이그린, AI 메시지는 밝은 표면색을 쓴다.
- 전송, 새 대화, 채팅 실행 아이콘은 오렌지 계열을 사용한다.
- 대화 위치 표시는 중립색을 기본으로 하고 현재 위치만 작은 오렌지 포인트로 표시한다.
- 스트리밍, 스크롤, 현재 작업 연결과 메시지 전송 동작은 유지한다.

### 공통 작업실

영상작업실 등 밝은 공통 조작 패널은 같은 토큰을 사용한다. 사진·영상 색 판단 영역은 기존 중성 다크 톤과 원본 색을 보존한다. 브릿지 미리보기는 이미지 색·비율을 유지하고 세로 사진 전체 보기 동작을 바꾸지 않는다.

## 상태와 데이터 보존

이번 변경은 CSS와 프레젠테이션 계층에 한정한다. API, 인증, 워커, NAS, 데이터 구조, 저장 로직, 폼 값, 선택 상태, 스크롤 상태, 창 이동·크기·최대화·닫기 동작을 변경하지 않는다.

## 반응형과 접근성

- 기존 좁은 창 레이아웃을 유지한다.
- 버튼과 입력이 잘리지 않도록 기존 breakpoints에서 확인한다.
- 포커스 가시성, 비활성 상태, 호버 상태, 본문 대비를 확인한다.
- 글자 굵기는 600을 넘기지 않는다.
- 아이콘은 기존 lucide 선 아이콘과 접근성 이름을 유지한다.

## 검증

- 타입 검사, 린트, 관련 테스트와 빌드를 실행한다.
- 실제 브라우저에서 콘티, 견적서, 일정, 고객관리, 올리비아 채팅을 넓은 화면과 좁은 창으로 확인한다.
- 기존 로고 에셋 비율과 색상을 확인한다.
- 문서 미리보기와 인쇄/PDF에 앱 배경색이 번지지 않는지 확인한다.
- 사진·영상 미리보기 원본 색상과 비율이 유지되는지 확인한다.
- 화면별 스크린샷을 남긴다.
