# 브릿지 이름 변경 폴더 우선순위

## 목적

선택한 작업 폴더에 번호가 붙은 하위 폴더와 폴더 밖 단독 사진이 함께 있을 때, 촬영 순서대로 전체 사진의 이름을 연속 변경한다.

## 승인된 동작

- 하위 폴더 이름 자체는 변경하지 않는다.
- 하위 폴더는 이름을 숫자 자연 정렬한다. 예: `1`, `2`, `10`.
- 각 하위 폴더 안의 사진을 먼저 처리한 뒤 다음 폴더로 넘어간다.
- 모든 하위 폴더 처리가 끝난 뒤 현재 폴더의 단독 사진을 처리한다.
- 기존 `일반 이름 변경`의 텍스트·시작 번호·자릿수를 그대로 사용하고, 전체 사진에 하나의 연속 번호를 부여한다.
- `하위 폴더까지 모두 처리`를 끄면 기존처럼 현재 폴더의 단독 사진만 처리한다.

## 보존 범위

- 상위 폴더명 붙이기와 직접 텍스트 붙이기 규칙
- 미리보기와 실행이 공유하는 정렬 결과
- 중복·오류 사전 차단
- 복사, 크기·SHA-256 검증 후 원본 이름 정리 방식
- 사진 이외 파일 제외

## 검증

- `1`, `2`, `10` 폴더 순서가 지켜진다.
- 폴더 밖 단독 사진은 마지막 번호를 받는다.
- 하위 폴더 처리를 끄면 단독 사진만 대상이 된다.
