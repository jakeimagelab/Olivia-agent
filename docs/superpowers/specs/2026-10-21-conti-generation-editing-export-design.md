# 콘티 생성·편집 및 출력 개선 설계

작성일: 2026-10-21

## 목표

- 자동 포함 장면과 사용자 선택 장면을 분리해 생성 화면의 중복을 없앤다.
- 진료과별 세부 촬영 항목 선택이 생성 결과에 남도록 한다.
- 화면에서 편집한 콘티와 타임테이블 값을 저장·재열기·엑셀·PDF가 동일하게 사용한다.
- 엑셀은 정확히 3시트, 인쇄 PDF는 정확히 3개 문서 구역으로 구성한다.

## 데이터 구조

- 기존 장면 필드는 `conti_scenes`에 그대로 저장한다.
- 사진/영상 값은 기존 `media` 컬럼에 저장한다.
- 자유 입력 촬영시간은 `studio_state.sceneMeta[sceneId].shootingTimeOverride`에 저장한다.
  - 속성이 없으면 자동 계산값을 사용한다.
  - 빈 문자열은 사용자가 의도적으로 비운 값으로 보존한다.
- 타임테이블의 날짜·시작·종료 수동값은 `studio_state.timelineOverrides[rowId]`에 저장한다.
  - 각 필드는 문자열 또는 `null`이다.
  - `null`은 의도적으로 비운 값이므로 자동 계산값으로 덮어쓰지 않는다.
- 기존 `studio_state` 값은 정규화 과정에서 그대로 호환한다.

## 생성 화면

- 단체사진 3개, 진료 연출, 수술 연출처럼 자동 포함되는 항목은 선택 목록에서 제외한다.
- 진료과 대분류를 선택하면 그 아래 세부 항목 체크 목록을 표시한다.
- 세부 항목은 `checked[categoryId]`에 저장한다.
- 생성 결과의 `procedures`와 설명·준비사항에 선택된 세부 항목을 반영한다.
- 장면 키와 이름을 기준으로 한 번 더 중복 제거해 같은 장면을 한 번만 생성한다.

## 편집 화면

- 구분은 기존 그룹 선택을 사용한다.
- 장면·촬영시간·분·사진/영상·키워드·설명·장소·인물·환자 역할·준비사항을 직접 편집한다.
- 여러 줄 필드는 Enter 줄바꿈을 유지한다.
- 타임테이블은 각 행에서 날짜·시작·종료를 직접 수정한다.
- 수동 시간이 없는 행만 자동 계산한다.
- 저장 확인 후 서버에서 다시 읽어 화면 상태를 갱신한다.

## 공통 출력 모델

- 화면, 엑셀, PDF가 별도의 계산을 하지 않도록 `lib/conti/exportModel.ts`에 출력 행 생성 함수를 둔다.
- 콘티 촬영시간은 수동값을 우선하고, 없을 때만 타임테이블 계산값을 사용한다.
- 타임테이블은 수동 날짜·시간이 반영된 파생 결과를 사용한다.

## 엑셀

- 시트는 `콘티`, `촬영 준비`, `당일 타임테이블` 3개만 생성한다.
- 제목 행, 짙은 녹색 머리글, 흰 글자, 옅은 그룹 구분, 줄바꿈, 열 너비, 틀 고정, 자동 필터, A4 가로 인쇄 설정을 적용한다.
- 당일 타임테이블 아래에 의료진 개인 촬영 구성을 같은 시트 안에 추가한다.

## PDF 인쇄

- 화면 탭과 별개로 인쇄 전용 문서 3장을 항상 렌더링하고 화면에서는 숨긴다.
- A4 가로 기준:
  1. 상세 콘티
  2. 촬영 준비 체크리스트
  3. 당일 타임테이블과 의료진 개인 촬영 구성
- 표 머리글은 `#155855`, 본문은 밝은 배경과 얇은 구조선, 그룹별 옅은 배경을 사용한다.
- 입력·버튼·드래그 UI는 인쇄하지 않는다.

## 검증

- 자동 포함 항목 비노출과 세부 항목 반영 테스트
- 빈 촬영시간과 타임테이블 수동 날짜·시작·종료 정규화·재열기 테스트
- 출력 모델의 화면·엑셀·PDF 데이터 일치 테스트
- 엑셀 시트명·열·인쇄 설정·스타일 검사
- 브라우저 인쇄 결과 3페이지 렌더링 및 잘림 확인
- 타입 검사와 관련 Vitest 실행
