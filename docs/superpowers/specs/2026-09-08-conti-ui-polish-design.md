# 콘티 UI 폴리시 디자인

## 목표

신규 콘티의 기능과 데이터 흐름을 유지하면서 제작, 결과표, 현장뷰의 시각적 완성도와 정보 위계를 높인다. OLIVIA OS의 크림, 딥그린, 오렌지 색상과 문서형 작업 도구의 성격을 유지한다.

## 검토한 방향

1. 기존 배치 유지 및 표면 스타일 조정: 변경 위험은 낮지만 사용자가 느끼는 개선 폭이 작다.
2. 따뜻한 에디토리얼 작업대: 제작 설정과 실시간 촬영 계획을 명확히 분리하고 콜시트 같은 정돈된 인상을 준다. 채택한다.
3. 어두운 AI 대시보드: 강한 시각 효과는 있으나 병원 문서 도구 및 OLIVIA OS와 이질적이다.

## 제작 화면

- 상단에 작은 `AI SHOOTING PLAN` 표식, 제목, 한 줄 안내를 배치한다.
- 왼쪽 설정 영역은 크림색 바탕의 폼 섹션으로 바꾸고, 각 입력 단계를 번호와 함께 구분한다.
- 진료과 촬영항목은 카드 나열 대신 얇은 행 구조로 표현한다.
- 대분류 선택 시 딥그린 테두리와 옅은 민트 배경으로 상태를 명확히 한다.
- 세부 시술은 작은 선택 칩으로 표시하고, 선택된 칩은 딥그린으로 반전한다.
- 오른쪽 예상 결과는 짙은 녹색 콜시트 패널로 구성한다. 장면 번호, 이름, 장소, 시간을 한눈에 본다.
- 생성 버튼은 오렌지색 pill CTA와 별도 원형 아이콘 영역으로 구성한다.

## 결과표

- 상단에 장면 수, 총시간, 준비 상태를 요약하는 콤팩트한 헤더를 둔다.
- 편집 도구는 주 작업과 보조 작업의 색 대비를 나눈다.
- 표 헤더와 행의 명암 대비, 셀 focus ring, 세부 시술 칩을 개선한다.
- 기능, 컬럼, 저장 API는 변경하지 않는다.

## 현장뷰

- 전체 진행률을 얇은 progress rail로 표시한다.
- 현재 장면을 가장 큰 딥그린 패널로 보여주고 장소, 시간, 인원, 준비사항을 구획화한다.
- 다음 장면은 작은 보조 패널로 유지한다.
- 장면 카드는 완료, 현재, 대기 상태를 색과 opacity로 구분한다.
- 카드 크기 조절, 드래그 순서 변경, 완료 API는 유지한다.

## 반응형 및 접근성

- 넓은 창은 설정과 미리보기의 비대칭 2열, 작은 창은 한 열로 전환한다.
- 모든 클릭 대상은 최소 36px 높이와 명시적인 focus-visible 상태를 갖는다.
- 색만으로 선택 상태를 전달하지 않고 체크 표시와 텍스트를 함께 쓴다.
- 애니메이션은 opacity와 transform만 사용하고 `prefers-reduced-motion`을 존중한다.

## 비범위

- taxonomy, 생성 규칙, API, DB schema, 공유 데이터 구조는 수정하지 않는다.
- 새로운 디자인 시스템이나 외부 UI 라이브러리를 추가하지 않는다.
- 콘티와 초상권 앱 구조를 다시 변경하지 않는다.

## 검증

- 타입 검사, 콘티 규칙 테스트, 린트, 프로덕션 빌드를 실행한다.
- 브라우저에서 데스크톱과 작은 창 크기로 피부과 선택 및 결과 미리보기를 확인한다.
