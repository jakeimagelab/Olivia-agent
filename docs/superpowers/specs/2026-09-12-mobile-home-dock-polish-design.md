# Olivia 모바일 홈·Dock 미세 조정 설계

## 목표

모바일 홈의 인사말 비중을 낮추고, 하단 Dock을 더 가볍고 투명하게 보이도록 조정한다. 현재 메뉴는 채움 배경 대신 작은 오렌지 점으로만 표시한다.

## 변경 범위

- `components/olivia-mobile/OliviaMobileShell.module.css`만 수정한다.
- 홈 인사말 제목의 현재 최소·최대 글자 크기를 각각 정확히 15% 줄인다.
  - `20px` → `17px`
  - `24px` → `20.4px`
  - 뷰포트 기반 중간값도 `5.75vw` → `4.8875vw`로 줄인다.
- Dock 배경색의 알파값을 `0.5`로 변경한다.
  - Dock 컨테이너 전체에 `opacity`를 적용하지 않아 아이콘과 글자는 선명하게 유지한다.
  - 기존 블러, 테두리, 그림자는 유지한다.
- 활성 메뉴의 연녹색 배경과 내부 그림자를 제거한다.
- 활성 메뉴 버튼의 하단 중앙에 지름 `5px` 오렌지 점을 표시한다.
  - 점은 버튼의 가상 요소로 구현하여 마크업과 접근성 구조를 바꾸지 않는다.
  - 아이콘·라벨 색상은 비활성 메뉴와 동일하게 유지하고 점만 활성 상태를 표현한다.

## 반응형·접근성

- 변경은 Olivia 모바일 Shell에만 적용한다.
- 메뉴의 터치 영역, 라벨, `aria-current="page"`는 그대로 유지한다.
- 오렌지 점은 시각적 보조이며 현재 메뉴 정보는 기존 `aria-current`로 전달한다.

## 검증 기준

- 375×812 모바일 화면에서 인사말이 기존보다 15% 작게 보인다.
- Dock 뒤의 콘텐츠가 50% 투명 배경과 블러를 통해 보인다.
- 어느 메뉴를 열어도 활성 버튼에 연녹색 면이 나타나지 않는다.
- 현재 메뉴에만 오렌지 점 하나가 표시된다.
- 타입 검사와 대상 파일 린트가 통과한다.

## 제외 범위

- Dock 높이, 메뉴 순서, 아이콘, 라벨 문구는 변경하지 않는다.
- 데스크톱 UI와 다른 모바일 화면의 레이아웃은 변경하지 않는다.
