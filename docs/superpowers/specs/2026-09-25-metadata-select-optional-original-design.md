# 메타데이터 셀렉 입력 단순화와 완료 RAW 제외 설계

## 목표

메타데이터 셀렉에서 `원본 JPG`를 선택 사항으로 바꾼다. `선택본 + RAW 원본`만으로도
파일명 또는 EXIF 촬영시간을 이용해 직접 매칭하고, 이미 보정한 사진은 일반 작업 RAW와 섞이지 않게
`Finished_RAW`로 분리한다.

## 입력과 매칭

- `고객 선택본` 표기는 `선택본`으로 바꾼다.
- `원본 JPG`와 `RAW 원본` 표기는 유지한다.
- `선택본`과 `RAW 원본`은 필수다.
- `원본 JPG`가 있으면 기존 방식대로 선택본 EXIF 촬영시간 → 원본 JPG → 같은 basename의
  RAW 순서로 매칭한다. 파일명이 바뀐 선택본을 위한 경로다.
- `원본 JPG`가 없으면 먼저 선택본 JPG와 RAW의 basename을 비교한다.
- 파일명이 바뀌어 basename이 일치하지 않는 선택본은 EXIF 촬영시간으로 RAW를 직접 찾는다.
  동일 초 후보가 여러 개면 자동 확정하지 않는다.

## 출력

- 일반 매칭은 기존대로 RAW 원본을 `Selected_RAW`에 복사한다.
- `이미 작업한 사진 제외`가 켜진 매칭은 선택한 폴더를 `RAW 작업본`으로 취급한다.
- 확정된 RAW 작업본은 같은 폴더의 `Finished_RAW`로 복사·용량 검증 후 원래 위치에서 삭제해 이동한다.
- 제외 모드에서는 복사본을 원래 위치에 남기지 않는다. 실패·중복 후보 RAW는 이동하지 않는다.
- 선택본 JPG는 항상 이동·삭제하지 않는다.
- `Finished_RAW`에 이미 있는 RAW는 이후 일반 매칭에서 `Selected_RAW`로 다시 복사하지 않는다.

## 안전 규칙

- `Finished_RAW`는 `storageLayout.ts`에 한 번만 선언한다.
- 복사·이동 전에 전체 대상의 이름 충돌을 검사한다.
- RAW 이동 중 실패하면 이미 이동한 파일을 원래 위치로 복원하고 `Finished_RAW`의 불완전 결과를 정리한다.
- 매칭 성공 건만 처리한다. 매칭 실패·중복 후보는 원래 위치에 그대로 두고 결과에 사유를 표시한다.
- 동일 RAW 또는 동일 출력 파일명으로 겹치는 행은 성공 건에서 제외해 자동 처리하지 않는다.
- 확인 화면에는 처리 대상, 매칭 실패로 건너뛸 대상, 이미 완료된 대상을 각각 표시한다.
- `Selected_RAW`와 `Finished_RAW` 자체를 입력 폴더로 지정하지 못하게 한다.

## 검증

- 원본 JPG 없는 직접 basename 매칭과 EXIF 직접 매칭의 성공·미발견·중복 후보 테스트
- 원본 JPG가 있는 기존 EXIF 매칭 회귀 테스트
- `Finished_RAW` 상수와 출력 폴더 제외 규칙 테스트
- 타입체크, 전체 테스트, 프로덕션 빌드
