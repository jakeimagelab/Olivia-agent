# Olivia 팝업 닫기 버튼 통일 설계

작성일: 2026-10-20

## 목적

Olivia의 모든 모달, 확인창, 전체화면 시트에 사용자가 즉시 알아볼 수 있는 닫기 버튼을 제공한다. 팝업의 기존 기능과 데이터 흐름은 바꾸지 않는다.

## 적용 범위

- 중앙 모달
- 확인·경고 대화상자
- 모바일 또는 데스크톱 전체화면 시트
- 이미지 크게 보기처럼 화면 위에 표시되는 모달형 오버레이
- 공통 `Modal`, `ConfirmDialog`와 화면별로 직접 구현된 팝업

다음은 팝업 닫기 버튼 적용 대상에서 제외한다.

- 드롭다운과 메뉴
- 툴팁
- 토스트와 일시적인 상태 안내
- 비모달 팝오버
- Olivia OS의 일반 앱 창 제어 버튼

## 닫기 버튼 규칙

- 팝업 헤더 우측 상단에 `lucide-react`의 `X` 아이콘을 둔다.
- 접근성 이름은 `aria-label="닫기"`로 통일한다.
- 터치 영역은 최소 `44px × 44px`로 한다.
- 밝은 팝업은 흐린 글자색, 어두운 팝업은 저채도 흰색을 사용한다.
- 새 강조색이나 채운 버튼을 만들지 않는다.
- 제목이 없는 팝업에도 우측 상단에 독립된 닫기 버튼을 표시한다.

## 동작

- 각 팝업이 이미 가진 `onClose`, 취소 함수 또는 상태 초기화 함수를 그대로 호출한다.
- 기존 ESC 닫기, 바깥 영역 클릭 닫기, 하단 취소 버튼 동작은 유지한다.
- 저장 중 닫기 제한, 변경사항 확인, 자동 저장 등 기존 보호 로직을 우회하지 않는다.
- 닫기 버튼 추가를 이유로 API, 데이터 구조, 저장 방식, 권한 로직을 변경하지 않는다.

## 구현 방식

1. 공통 `Modal`과 `ConfirmDialog`에 닫기 버튼을 보장한다.
2. `role="dialog"`, `role="alertdialog"`, `aria-modal="true"`와 모달 오버레이 패턴을 검색해 직접 구현 팝업을 감사한다.
3. 이미 닫기 아이콘이 있는 팝업은 중복 추가하지 않는다.
4. 글자 형태의 `닫기`만 있는 모달은 우측 상단 X를 추가하되 기존 글자 버튼은 기능상 필요한 경우 유지한다.
5. 공통 컴포넌트로의 대규모 리팩터링은 하지 않는다.

## 검증

- 정적 감사: 대상 팝업마다 `aria-label="닫기"` 버튼 또는 공통 닫기 버튼이 있는지 확인한다.
- 타입 검사와 린트를 실행한다.
- 대표 밝은 모달, 어두운 사진 모달, 확인창, 모바일 시트를 열어 X 표시와 닫기 동작을 확인한다.
- 좁은 폭과 넓은 폭에서 제목·주 실행 버튼과 겹치지 않는지 확인한다.

## 보존 사항

- 드롭다운·메뉴·툴팁·토스트의 기존 표현
- 기존 팝업의 저장·취소·확인 로직
- 기존 ESC와 배경 클릭 동작
- 화면별 밝음·어두움 톤
- 데이터 및 API 동작
