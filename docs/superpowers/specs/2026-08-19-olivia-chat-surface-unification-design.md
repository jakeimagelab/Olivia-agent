# Olivia 채팅 표면 통일 설계

## 목표

홈에서는 Olivia 채팅을 중앙 작업 공간의 주인공으로 넓게 보여주고, 다른 페이지에서는 본문을 침범하지 않는 호출형 채팅으로 제공한다. 모든 표면은 같은 Conversation Store를 사용하며, 긴 대화 가이드는 실제 탐색 도구로 동작해야 한다.

## 범위

- 홈 채팅과 Composer의 가로 폭 확대
- 홈 이외 페이지의 Olivia 기본 상태를 닫힌 원형 아이콘으로 변경
- 아이콘 클릭 시 오른쪽 오버레이 드로어 열기
- 긴 대화 가이드의 표시 조건과 클릭·터치 팝업 동작 수정
- 홈·드로어·워크스페이스 채팅의 헤더, 타이포그래피, 메시지, Composer 스타일 통일
- 기존 Conversation Store, 메시지 영속화, Agent 실행 로직 유지

## 화면 동작

### 홈

- 사이드바와 우측 홈 컨트롤을 제외한 중앙 가용 폭의 92~96%를 채팅 카드가 사용한다.
- 대형 화면에서도 임의의 좁은 `max-width` 때문에 채팅이 중앙에 작게 남지 않는다.
- 채팅 카드, 메시지 목록, Composer는 동일한 폭 축을 사용한다.
- 전체 페이지 스크롤 없이 기존 viewport 고정 구조를 유지한다.

### 홈 이외 페이지

- 초기 상태에는 우측 하단 Olivia 원형 아이콘만 표시한다.
- 아이콘을 클릭하면 약 440~480px 너비의 오른쪽 오버레이 드로어가 열린다.
- 드로어는 본문 레이아웃 폭을 줄이지 않고 위에 겹쳐 열린다.
- 배경 스크림 또는 닫기 버튼으로 닫을 수 있다.
- 닫았다 다시 열어도 동일한 `useOliviaConversationStore.messages`를 그대로 표시한다.

### 모바일·태블릿

- 기존처럼 원형 아이콘에서 전체 높이 드로어를 연다.
- 데스크톱과 같은 상태 모델과 접근성 라벨을 사용한다.

## 긴 대화 가이드

- 사용자-Assistant 교환이 4개 이상일 때만 가이드 레일을 표시한다.
- 각 틱은 최소 터치 영역을 가진 실제 `button`이다.
- 클릭 또는 터치하면 해당 교환의 시간, 주제, 사용자 요청, Assistant 요약을 팝업으로 표시한다.
- 팝업은 채팅 컨테이너의 overflow에 잘리지 않는 방향으로 배치한다.
- `이 대화로 이동`을 누르면 해당 메시지로 부드럽게 이동하고 팝업을 닫는다.
- 활성 대화 틱은 색상과 외곽선으로 구분한다.
- 교환이 임계값보다 적으면 레일 공간 자체를 제거해 불필요한 진녹색 막대를 보이지 않는다.

## UI 통일

- Pretendard 기반 공통 타이포그래피를 모든 채팅 표면에 적용한다.
- OLIVIA 헤더의 높이, 아이콘, 제품명, 상태 문구, 새 대화·닫기 컨트롤을 공통 규칙으로 맞춘다.
- 메시지 글자 크기와 행간을 홈과 드로어에서 동일한 가독성 범위로 맞춘다.
- Composer의 radius, border, shadow, placeholder, 전송 버튼을 공통 토큰으로 통일한다.
- 표면별 차이는 컨테이너 폭과 배치뿐이며 채팅 자체의 시각 언어는 유지한다.

## 컴포넌트 경계

- `OliviaPersistentChat`: 홈 이외 페이지에서 아이콘 및 오버레이 드로어의 열림 상태를 담당한다.
- `OliviaConversation`: 메시지·Composer·헤더와 가이드 표시 조건을 담당한다.
- `OliviaConversationGuide`: 틱 선택, 팝업, 메시지 이동만 담당한다.
- CSS: 홈 폭, 오버레이 위치, 공통 채팅 토큰과 반응형 규칙을 담당한다.
- Conversation Store와 API는 수정하지 않는다.

## 접근성 및 오류 처리

- 아이콘, 닫기, 가이드 틱에 명확한 `aria-label`을 제공한다.
- 드로어 닫힘 상태에서는 내부 요소를 키보드 포커스 순서에서 제외한다.
- Escape 키로 드로어와 가이드 팝업을 닫을 수 있게 한다.
- 팝업 대상 메시지가 사라진 경우 선택 상태를 자동 해제한다.

## 검증

- 1920px 및 1440px 데스크톱에서 홈 채팅 폭을 시각 확인한다.
- 홈 이외 페이지 최초 진입 시 아이콘만 표시되는지 확인한다.
- 아이콘 클릭, 닫기, 재열기 후 메시지가 유지되는지 확인한다.
- 3개 이하 교환에서는 가이드가 없고, 4개 이상에서는 틱이 표시되는지 확인한다.
- 각 틱 클릭·터치, 팝업 표시, 메시지 이동을 확인한다.
- 홈·드로어의 폰트, 헤더, 메시지, Composer를 비교한다.
- typecheck, 테스트, production build를 실행한다.

## 제외 사항

- Conversation DB 구조 변경
- Agent 또는 Tool 실행 방식 변경
- 홈의 다른 정보 패널 구조 변경
- 새로운 대화 검색·요약 기능 추가
- 브랜드 컬러의 전면 재설계
