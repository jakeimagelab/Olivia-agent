# 콘티 공통 시작 장면·선택형 개인 촬영 설계

## 목표

- 모든 자동 생성 콘티의 S1~S3을 `단체사진`, `단체 하모니컷`, `인포데스크 하모니컷`으로 고정한다.
- 장면 안의 의료진 인원과 가운 수는 이름이 입력된 의료진 수로 계산한다.
- `헤어메이크업 · 준비`와 `의료진 프로필`은 생성 화면에서 선택한 경우에만 넣는다.
- 콘티 표의 텍스트 셀은 Enter로 줄바꿈하고, 줄바꿈을 기존 저장 경로로 보존한다.
- Olivia OS에서 생성 직후 문서 컨텍스트가 바뀌어도 콘티 창을 다시 마운트하지 않는다.

## 생성 규칙

1. 공통 시작 장면 세 개를 진료과 taxonomy와 분리된 공통 템플릿으로 둔다.
2. 세 장면을 선택 항목보다 먼저 생성하고 AI 보강 대상에서 제외한다.
3. 의료진 수는 공백 이름을 제외한 명단 길이를 쓰며, 최소 1명으로 처리한다.
4. 진료 연출과 수술 연출은 기존처럼 기본 개인 촬영 장면으로 유지한다.
5. 헤어메이크업과 프로필은 기본 꺼짐인 두 체크 항목으로 제공한다.
6. 촬영시간은 고정 문구를 저장하지 않고 기존 타임테이블 계산 결과를 유지한다.

## 편집 규칙

- 장면명, 키워드, 설명, 장소, 인물, 환자 역할, 준비사항을 여러 줄 입력으로 바꾼다.
- 텍스트 셀의 Enter는 줄바꿈이며, Tab은 다음 셀로 이동한다.
- 분 입력처럼 한 줄 숫자 셀의 Enter만 다음 행으로 이동한다.
- 저장 API와 데이터 컬럼은 기존 문자열 필드를 그대로 사용한다.

## 상태 보존

- 데스크톱 창 콘텐츠 key에서 `conti` 앱은 창 id만 사용한다.
- 문서가 생성되어 client/document 컨텍스트가 채워져도 컴포넌트 상태와 생성된 run id가 유지된다.
- 다른 앱의 기존 컨텍스트별 재마운트 동작은 변경하지 않는다.

## 검증

- 생성 순서, 동적 인원 문구, 선택형 장면 조합을 순수 함수 테스트로 확인한다.
- 안과 선택 목록에서 고정 장면이 빠지고 중복 생성되지 않는지 확인한다.
- 표의 텍스트 셀이 textarea이며 Enter 이동 처리 대상이 아닌지 확인한다.
- 콘티 데스크톱 콘텐츠 key가 client/project 변화에도 안정적인지 확인한다.
