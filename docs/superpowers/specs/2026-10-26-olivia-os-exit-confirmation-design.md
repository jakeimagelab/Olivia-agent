# Olivia OS 종료 확인 설계

작성일: 2026-10-26

## 목적

Olivia OS 사용 중 `Command+W`, `Command+Q`, 새로고침 또는 다른 주소 이동을 실수로 실행했을 때 브라우저의 기본 페이지 이탈 확인창을 표시한다.

## 현재 동작

- `DesktopSurface`가 `Command+W`를 가로채 활성 Olivia 앱 창을 즉시 닫는다.
- Olivia OS 루트에는 페이지 이탈을 막는 `beforeunload` 처리기가 없다.
- 각 앱 창의 닫기 버튼과 상단 메뉴의 `활성 창 닫기`는 별도 동작으로 존재한다.

## 변경 설계

1. `OliviaDesktopContent`가 마운트된 동안 `beforeunload` 이벤트 처리기를 등록한다.
2. 처리기는 `event.preventDefault()`를 호출하고 `event.returnValue`를 설정해 브라우저 기본 확인창을 요청한다.
3. 컴포넌트가 언마운트되면 처리기를 제거한다.
4. `DesktopSurface`의 `Command+W` 가로채기 분기를 제거한다. 따라서 `Command+W`는 브라우저의 탭 닫기 흐름으로 이어지고 `beforeunload` 확인을 거친다.
5. `Command+M`으로 활성 Olivia 앱 창을 최소화하는 기존 단축키는 유지한다.
6. Olivia 앱 창은 기존 빨간 닫기 버튼 또는 상단 메뉴의 `활성 창 닫기`로 계속 닫을 수 있다.

## 브라우저 제한

- 확인 문구는 브라우저가 결정한다. 사이트가 원하는 한국어 문장을 직접 지정할 수 없다.
- 최신 브라우저는 사용자와 페이지의 상호작용이 있었던 경우에만 확인창을 표시할 수 있다.
- `Command+Q`의 최종 처리 여부는 브라우저와 운영체제 정책에 따르지만, 페이지가 종료 절차를 밟으면 같은 `beforeunload` 보호가 적용된다.

## 범위

- Olivia OS 루트에서만 보호한다.
- 공개 페이지, 고객 포털, 공유 링크에는 적용하지 않는다.
- 저장 방식, 앱 창 상태 복원, 사진 작업 로직은 변경하지 않는다.

## 검증

- 단위 테스트로 Olivia OS가 `beforeunload` 처리기를 등록·해제하는지 확인한다.
- `DesktopSurface`에서 `Command+W` 내부 창 닫기 처리가 제거됐는지 확인한다.
- `Command+M` 최소화는 계속 동작하는지 확인한다.
- 실제 Chromium에서 사용자 클릭 후 새로고침과 탭 닫기를 시도해 브라우저 기본 확인창을 확인한다.
- 타입 검사와 관련 테스트를 실행한다.
