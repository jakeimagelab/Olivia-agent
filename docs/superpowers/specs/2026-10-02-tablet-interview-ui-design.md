# 태블릿 인터뷰 UI 정리

## 범위

Olivia 음성기록의 **가로 태블릿 인터뷰 화면**만 첨부 레퍼런스의 네 단계로 정리한다. 일반 녹음, 모바일 화면, 인터뷰 질문 데이터, PDF 생성 및 녹음 저장 로직은 변경하지 않는다.

## 화면 구성

1. 질문 선택: 인터뷰 정보 34%, 질문 선택 66%의 2단 레이아웃. 왼쪽 정보 카드는 sticky, 오른쪽 질문 헤더는 선택 수를 계속 표시한다.
2. 질문 순서: 선택한 질문을 넓은 단일 패널로 보여주고, 동일한 크기의 위·아래 버튼과 하단 고정 액션 바를 둔다.
3. 준비 완료: 병원·대상·일정 요약과 PDF 미리보기/다운로드/인터뷰 시작을 Dock 위에서 항상 접근 가능하게 둔다.
4. 인터뷰 진행: 병원·대상·질문 진행 수·시간을 상단에 두고, 현재 질문과 녹음 제어를 화면 중심에 둔다.

## 레이아웃 원칙

- Olivia 상단 바와 Dock은 기존 Shell을 그대로 사용한다.
- 태블릿 앱 콘텐츠만 스크롤하며, 100vh 대신 Shell이 제공하는 높이를 따른다.
- 단계 전환 때 기존 태블릿 스크롤 컨테이너를 상단으로 되돌린다.
- 900px 이상에서만 2단 구성을 사용하고, 그보다 좁으면 기존 단일 열 레이아웃을 유지한다.

## 검증

- 태블릿 가로에서 네 단계의 헤더·Dock·고정 액션이 겹치지 않는다.
- Accordion과 질문 순서가 길어져도 질문 영역만 자연스럽게 스크롤된다.
- 인터뷰 진행 화면에서 현재 질문, 녹음 상태, 이전/다음·일시정지·종료 제어가 한 화면에서 보인다.
