# Olivia 스플래시 → 홈 전환 디자인

## 목표

앱 최초 진입 시 스플래시와 실제 Olivia 홈을 서로 다른 화면처럼 교체하지 않고, 하나의 장면이 자연스럽게 완성되는 경험으로 연결한다. 기존 대화, 워크스페이스, 데이터 로딩, 라우팅 동작은 변경하지 않는다.

## 현재 문제

- 스플래시가 실제 홈과 무관한 560×220px 가상 채팅 카드를 그린다.
- 실제 홈 채팅은 최대 1080px이며 로고와 카드 좌표도 달라 스플래시 종료 순간 크기와 위치가 튄다.
- 스플래시가 루트 레이아웃에 마운트되어 홈이 아닌 경로를 처음 열어도 표시될 수 있다.
- 스플래시와 홈이 각자 독립된 애니메이션 시간을 사용해 시각적 인계 지점이 없다.

## 선택한 접근

가상 카드 morph를 제거하고, 실제 홈이 뒤에서 이미 렌더링된 상태에서 스플래시 오버레이만 걷히는 공유 시각 전환을 사용한다.

1. 홈 경로에서만 세션당 한 번 스플래시를 표시한다.
2. 스플래시는 중앙 Olivia 로고와 브랜드명만 담당한다.
3. 실제 홈은 처음부터 마운트해 레이아웃과 데이터 로딩을 미리 시작한다.
4. 전환 후반부에 실제 홈의 로고·Greeting·채팅창·Quick Action을 순서대로 드러낸다.
5. 스플래시 로고가 작아지며 투명해지는 동안 실제 홈 로고가 같은 시각적 중심에서 이어받는다.
6. 전체 전환은 약 1.4~1.7초로 제한한다.

정확한 DOM 좌표를 매 프레임 계산하는 FLIP 방식은 사용하지 않는다. 현재 홈의 반응형 구조에서는 복잡성과 좌표 오차 위험이 커서, 겹치는 두 장면의 transform/opacity 인계가 더 안정적이다.

## 컴포넌트 책임

### `OliviaSplash`

- 현재 경로가 홈인지 판별한다.
- 세션 표시 여부와 `prefers-reduced-motion`을 확인한다.
- 시작·인계·완료 단계를 CSS 클래스 또는 명확한 상태로 노출한다.
- 완료 시 오버레이를 DOM에서 제거한다.
- 가상 채팅 카드와 화면 크기에 따른 수동 corner 좌표 계산을 제거한다.

### `OliviaAdaptiveStage`

- 스플래시 종료를 기다리지 않고 항상 실제 홈을 렌더링한다.
- 최초 홈 진입 중에만 전용 entrance 상태를 받는다.
- 로고/Greeting, 채팅, Quick Action의 등장 순서를 담당한다.
- 대화 중이거나 워크스페이스가 열린 기존 레이아웃 모드는 건드리지 않는다.

### 루트/홈 연결

- 스플래시 표시 범위는 홈(`/admin/dashboard/home`, 필요한 경우 기존 홈 alias)으로 제한한다.
- 경로 이동이나 다른 페이지 새로고침에서는 스플래시를 띄우지 않는다.
- 스플래시 상태 전달은 전역 대화 Store나 Layout Store에 섞지 않고, 진입 표현 전용의 작은 이벤트/DOM 상태로 격리한다.

## 모션 시퀀스

1. **도착 (0–350ms)**: 흰색에 가까운 배경 위 Olivia 로고와 브랜드명이 부드럽게 나타난다.
2. **인계 (350–950ms)**: 스플래시 로고가 약간 축소·상향 이동하며 흐려지고, 실제 홈 로고와 Greeting이 등장한다.
3. **홈 완성 (700–1450ms)**: 실제 채팅 카드가 10–14px 아래에서 올라오며 나타나고 Quick Action이 짧은 간격으로 뒤따른다.
4. **정착 (1450–1700ms)**: 오버레이가 완전히 제거되고 홈의 기존 idle 애니메이션만 유지된다.

모션은 `transform`과 `opacity`만 사용한다. 채팅 카드의 width/height를 애니메이션하지 않는다.

## 반응형과 접근성

- 데스크톱, 태블릿, 모바일 모두 같은 단계 구조를 사용하되 이동 거리는 모바일에서 줄인다.
- `prefers-reduced-motion: reduce`에서는 250ms 안팎의 단순 crossfade만 적용한다.
- 오버레이가 표시되는 동안만 포인터 입력을 막고, 종료 후 즉시 DOM에서 제거한다.
- 장식 로고는 스크린리더에서 숨긴다.

## 오류 및 예외 처리

- `sessionStorage` 접근 실패 시 스플래시 없이 홈을 즉시 표시한다.
- 애니메이션 종료 이벤트가 누락돼도 타이머 fallback으로 오버레이를 제거한다.
- 홈에 이미 대화 또는 워크스페이스 상태가 있으면 긴 entrance를 생략하고 짧게 표시한다.

## 검증 기준

- 최초 홈 진입에서 스플래시와 홈 사이에 흰 화면, 좌표 점프, 카드 크기 점프가 없다.
- 홈이 아닌 페이지를 직접 열 때 스플래시가 나타나지 않는다.
- 같은 세션에서 홈 재진입 시 스플래시가 반복되지 않는다.
- 대화 Store와 Layout Store 상태가 초기화되지 않는다.
- 모바일과 모션 감소 환경에서 정상 종료된다.
- TypeScript 검사와 production build가 통과한다.

## 범위 밖

- 홈 레이아웃 재설계
- 채팅 기능 및 API 변경
- 전역 페이지 전환 변경
- 브랜드 컬러나 타이포그래피 재정의
- 다른 페이지의 로딩 UI 변경
