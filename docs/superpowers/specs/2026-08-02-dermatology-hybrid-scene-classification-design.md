# 피부과·병원 촬영 하이브리드 Scene 분류 설계

## 목표

병원 현장촬영의 시간 중심 Scene 분류를 사람·장비·장소·자세·시간을 함께 사용하는 하이브리드 엔진으로 교체한다. 시간은 큰 후보 구간과 강제 경계를 만드는 용도로만 사용하고, 승인 전에는 JPG와 RAW를 이동하지 않는다. 기존 시간 전용 방식은 빠른 분류로 유지한다.

## 범위

1차 구현에는 로컬 시각 특징 스캔, 피부과 경계 AI 검증, Boundary Score, 경계 안정화, 병합·분할 검토 UI, 로컬 수정 기록, 정확도 평가, 중단·복원, 승인 후 안전한 파일 정리가 포함된다. 서버 작업 큐, 얼굴 임베딩 모델, 피부과 외 정밀 프로필은 후속 범위다.

## 처리 흐름

1. JPG와 RAW를 수집하고 JPG는 `DateTimeOriginal → CreateDate/DateTimeDigitized → IFD0 DateTime → mtime → 파일명` 순으로 정렬한다.
2. 5분을 넘는 시간 간격은 강제 경계로 만들고, 그 사이를 분석 후보 구간으로 유지한다.
3. 모든 JPG에 dHash, 색상 히스토그램, 배경 영역, 구도, 밝기 특징을 계산한다.
4. 이전 3장과 다음 3장의 중앙값 특징을 비교해 경계 후보를 찾는다.
5. 후보 전후 2~3장만 1,080px, JPEG 0.82, Vision high로 의미 분석한다.
6. 사람 0.28, 장소 0.24, 장비 0.22, 장면 의미 0.12, 시각 0.07, 자세 0.04, 시간 0.02, 촬영 거리 0.01로 Boundary Score를 계산한다.
7. 0.72 이상은 분리, 0.55~0.71은 추가 검증, 0.55 미만은 유지한다. 강제 전환 규칙과 짧은 Scene 안정화를 적용한다.
8. 최종 Scene 계획을 사용자에게 보여주고 병합·분할·이름 변경·승인을 받는다.
9. 승인 후에만 JPG 폴더 생성과 RAW 정리를 실행한다.

## 기본 설정

- 모드: 병원 현장촬영은 정밀 분류 기본
- 프로필: dermatology
- hard gap: 5분
- soft gap: 25초
- 최소 Scene: 2장
- window: 좌우 각 3장
- 로컬 후보 임계값: 0.42
- soft gap 보조 임계값: 0.28
- 특징 동시 처리: 3개
- AI 동시 처리: 2개, 최대 2회 재시도

## 사람·장소·장비

사람 변화는 실명이나 얼굴 이미지를 저장하지 않고 사람 수, 역할, 복장, 위치, 전후 인물 그룹 변화로 계산한다. 장소는 배경 구조, 가구, 베드, 상담 데스크, 대형 장비 배치와 공간 유형을 사용한다. 장비는 없음, 상담 환경, 레이저·리프팅, 주사, 피부관리, 기타 의료 장비로 대분류한다.

사람+장소, 사람+장비, 장소+장비, 상담→시술, 앉음→누움+장비 등장은 강제 분리한다. 동일 사람·장소·장비에서 와이드→클로즈업 또는 장비 전체→핸드피스 디테일만 변하면 유지 보정을 적용한다.

## 검토·기록·평가

Scene 카드에는 시작·마지막 썸네일, 이미지 수, 시간 범위, 추천명, 대표 타입, 승인 상태를 표시한다. 경계 카드에는 전체 점수, 항목별 점수, 분리 이유와 실패 상태를 표시한다. 사용자는 앞뒤 병합, 원하는 사진 위치 분할, 이름 변경, 개별·전체 승인을 수행할 수 있다.

수정 기록은 작업 중 브라우저 저장소에 보존하고 최종적으로 `REPORT/scene_corrections.json`과 CSV에 저장한다. 정확도 평가는 사용자 정답 경계와 자동 경계를 ±1장 일대일 매칭해 Precision, Recall, F1, Scene Purity, 과분할률, 미분할률을 계산한다. 실제 정답 데이터가 없으면 90% 달성을 주장하지 않는다.

## 실패·복구와 호환성

손상 이미지와 EXIF 없는 이미지는 별도 로그에 남기고 처리는 계속한다. AI 실패는 로컬 특징 판정과 검토 필요 상태로 복구한다. 중단 시 체크포인트를 저장하고 동일 폴더 재선택 시 이어서 처리한다. 파일 정리는 복사와 크기 확인 후 원본을 제거하고 `REPORT/file_operation_journal.json`에 기록한다.

기존 사진 가져오기, 빠른 분류, Scene 결과, JPG/RAW 구분, 파일명, 폴더명 수정, RAW basename 매칭, NAS, 갤러리, 고객 셀렉, 품질 검사, 스튜디오 분류는 유지한다.

## 검증

순수 엔진 단위 테스트, 요청서 20개 상황의 합성 통합 테스트, 기존 빠른 분류와 RAW 매칭 회귀 테스트를 추가한다. 브라우저에서는 승인 전 무이동, 진행률, 중단·복원, 병합·분할, 승인 후 폴더 생성을 확인한다. TypeScript, Vitest, lint, Next.js build를 통과시킨다.
