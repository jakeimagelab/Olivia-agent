# 개인별 셀렉 인원 매칭 확인

## 목적

사진을 올린 뒤 진행 현황을 보기 전에 폴더 이름과 실제 사진이 올바른 사람에게 연결됐는지 확인한다.

## 화면

- 행사 상세의 첫 탭을 `인원 매칭`으로 둔다.
- 등록된 사람 전부를 `이름 · 대표 사진 1장 · 등록 장수 · 원본 폴더` 카드로 보여준다.
- 이 단계에서는 연결을 수정하지 않는다. 잘못된 폴더는 원본 폴더명을 고친 뒤 다시 올리는 기존 흐름을 유지한다.
- `확인하고 진행 현황 보기`로 기존 진행 현황 탭으로 이동한다.
- 진행 현황의 고객 선택 칸에도 선택 전 등록 대표 사진을 바로 표시한다. 선택 장수는 계속 `0 / 필요 장수`로 구분한다.
- 사진 업로드가 끝나면 인원 매칭 탭으로 자동 이동한다.

## 데이터

- 행사 사진 전체를 페이지 단위로 읽어 1,000장 제한 없이 사람별 장수를 계산한다.
- 사람별 `sort_order`가 가장 앞선 사진 한 장만 대표 사진으로 사용한다.
- 대표 썸네일만 일괄 서명하여 관리자 응답에 포함한다.

## 검증

- 1,000장을 넘는 행사에서도 모든 인원과 정확한 등록 장수를 보여준다.
- 한 사람에게 여러 사진이 있어도 대표 사진은 한 장만 반환한다.
- 로컬 및 Mac Studio 업로드 완료 뒤 인원 매칭 탭으로 이동한다.
- 사진이 없는 사람도 누락하지 않고 빈 상태로 표시한다.
