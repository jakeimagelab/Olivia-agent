# Review Studio Compact Text Toolbar Design

## Goal

리뷰 콘텐츠 편집기의 텍스트 도구를 데스크톱에서 가로 스크롤 없이 한 줄로 유지한다. 크기·행간·자간 슬라이더는 입력 박스처럼 보이는 외곽 컨테이너를 제거하고, 라벨·얇은 선·점·현재 값만 보여준다.

## Current Problem

- `contextTools`가 넘침을 `overflow-x: auto`로 처리해 사용자가 오른쪽 기능을 찾으려면 가로로 스크롤해야 한다.
- 각 `ToolbarRange`가 고정 124px 폭, 테두리, 흰 배경, 패딩을 가져 실제 슬라이더보다 불필요하게 크다.
- 자동 줄바꿈의 긴 텍스트 라벨이 한 줄 공간을 많이 차지한다.

## Considered Approaches

1. 모든 컨트롤의 폭만 일괄 축소: 구현은 간단하지만 작은 화면에서 다시 넘치며 슬라이더 조작성이 빠르게 나빠진다.
2. 도구를 두 줄로 배치: 조작 영역은 넉넉하지만 사용자가 요청한 단일 행 조건과 맞지 않는다.
3. 반응형 단일 행: 기본 데스크톱에서는 모든 라벨을 유지하고, 좁은 편집 영역에서는 보조 라벨을 축약한다. 기능을 숨기지 않으면서 가로 스크롤을 없앨 수 있어 이 방식을 채택한다.

## Design

### Toolbar Layout

- `.contextTools`는 `overflow-x: visible/hidden` 기반의 단일 행으로 유지하고 가로 스크롤을 제거한다.
- 폰트 선택 폭, 아이콘 버튼 크기, 그룹 간격을 소폭 줄인다.
- 모든 도구는 `flex-shrink` 규칙을 명시해 선택창과 슬라이더가 사용 가능한 폭 안에서 함께 축소되게 한다.
- 좁은 편집 영역에서는 컨텍스트의 “텍스트” 라벨을 숨기고 “자동 줄바꿈”을 체크 아이콘 중심의 축약 표현으로 바꾼다. 기능 자체는 숨기지 않는다.

### Range Controls

- 외곽 `border`, `background`, `border-radius`, 박스형 패딩을 제거한다.
- 구성은 `라벨 | range track/thumb | 값`의 세 요소만 남긴다.
- 트랙은 2px, thumb는 10px로 유지해 Olivia의 딥그린 톤과 현재 정밀도를 보존한다.
- 크기·행간·자간의 min/max/step과 상태 업데이트 로직은 변경하지 않는다.
- 키보드 포커스는 슬라이더 자체의 포커스 링으로 계속 표시한다.

### Responsive Behavior

- 넓은 화면: 라벨과 값 전체 표시.
- 좁은 데스크톱 편집 영역: 간격·선택창·슬라이더가 유연하게 줄고 자동 줄바꿈 라벨이 축약된다.
- 한 줄과 모든 기능 접근을 유지하며, 가로 스크롤이나 두 줄 배치는 사용하지 않는다.

## Scope

변경 대상은 Review Studio 텍스트 컨텍스트 툴바와 관련 CSS에 한정한다. Canvas renderer, 텍스트 값 계산, 저장 데이터, PNG/PDF 출력에는 영향을 주지 않는다.

## Verification

- 텍스트 레이어 선택 시 툴바 전체가 한 줄이며 가로 스크롤이 생기지 않는다.
- 크기·행간·자간에 외곽 박스가 없고 선과 점만 보인다.
- 세 슬라이더 값과 자동 줄바꿈 토글이 기존과 동일하게 작동한다.
- 대표 데스크톱 폭과 좁은 편집 영역에서 툴바 오버플로를 브라우저로 확인한다.
- TypeScript 검사와 관련 테스트, 프로덕션 빌드를 실행한다.
