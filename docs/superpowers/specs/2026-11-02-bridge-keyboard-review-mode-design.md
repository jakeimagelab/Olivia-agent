# Olivia Bridge 키보드 범위 선택·리뷰 모드 설계

작성일: 2026-11-02  
대상: `components/olivia-bridge/OliviaBridgeWorkspace.tsx`, `components/olivia-bridge/OliviaBridgeWorkspace.module.css`와 순수 선택 보조 로직·테스트

## 목표

Bridge에서 키보드만으로 여러 사진을 범위 선택하고, 선택한 사진을 비교 리뷰하면서 실제 선택을 추린다. 리뷰에서 바뀐 선택·별점·컬러·제외 상태는 기존 `selectedIds`, `jpgRatingsByName`, `colorLabels`, `excludedIds`에 즉시 반영하며 별도 저장소나 API를 만들지 않는다.

## 진입과 기본 선택

- 일반 Bridge 그리드에서 `Shift + 방향키`는 현재 범위 앵커부터 방향키가 가리키는 사진까지 선택한다. 방향을 되돌리면 범위도 줄어든다.
- 기존 방향키는 지금처럼 포커스를 한 장씩 옮기고 그 사진 한 장을 선택한다.
- `Command/Ctrl + B`는 현재 선택으로 리뷰 모드를 연다. 선택이 없으면 열지 않고, 한 장이면 단일 리뷰로 연다.
- 리뷰 진입 순서는 현재 Bridge 파일 순서로 고정한다.

## 리뷰 레이아웃

- 리뷰는 Olivia Bridge 창 내부를 덮는 `#2A2A2A` 중성 회색 오버레이로 연다.
- 1장은 한 장 크게 보기로 표시한다.
- 2~4장은 균등 비교 그리드로 표시한다. 활성 사진은 민트 외곽선으로 구분한다.
- 5장 이상은 사용자가 준 참고 화면처럼 활성 사진을 가운데 크게 두고 앞뒤 사진을 뒤로 겹친 덱으로 표시한다. 화면에는 활성 사진과 가까운 이웃만 렌더링하고, `←/→` 이동에 따라 덱이 순환한다.
- 파일명, 현재 위치/남은 선택 수, 별점·컬러·제외 상태와 단축키 안내를 한 하단 바에 모은다.

## 리뷰 키보드 동작

- `←/→`: 활성 사진을 이전/다음 사진으로 이동한다. 덱은 끝에서 처음으로 순환한다.
- `↓`: 활성 사진을 `selectedIds`에서 실제로 제거한다. 제거한 사진은 리뷰 화면에서 즉시 빠지고 다음 남은 사진이 활성화된다.
- `↑`: 가장 최근에 `↓`로 제거한 사진을 원래 순서 위치에 복원하고 다시 활성화한다. 복원 기록은 리뷰를 닫으면 버린다.
- `1~5`: 활성 사진 별점, `0`: 활성 사진 별점 해제.
- `6~9`: 활성 사진 컬러 레이블 토글.
- `X`: 활성 사진 제외 토글. 선택 상태는 유지한다.
- `Space`: 활성 사진을 기존 전체화면 미리보기로 연다.
- `Escape`: 전체화면이면 전체화면만 닫고, 리뷰 화면이면 리뷰를 닫는다. 리뷰에서 남은 `selectedIds`는 그대로 유지한다.

## 전체화면 미리보기

- 기존 Space 미리보기의 `1~5`, `0`, `6~9` 처리를 유지하고 활성 사진 한 장에만 적용한다.
- 리뷰에서 연 경우 전체화면의 `←/→`는 리뷰 순서를 따라가고, 닫으면 같은 활성 사진으로 리뷰에 돌아온다.
- 전체화면은 기존처럼 `#2A2A2A`와 `object-fit: contain`을 유지한다.

## Bridge 작업면 색

- 사진 썸네일 목록인 `.browserPanel`, `.browserHeader`, `.fileArea`의 작업면은 진한 그린 `#103E36`으로 바꾼다.
- 썸네일 카드·선택 민트·별점·컬러 표시는 현재 대비와 의미를 유지한다.
- 오른쪽 미리보기의 사진 캔버스, 리뷰 모드, Space 전체화면은 사진 색을 판단하는 영역이므로 `var(--ui2-photo, #2A2A2A)`를 유지한다.
- 폴더 패널, 하단 도구, 개인별 셀렉 불러오기 등 요청 밖의 색과 기능은 바꾸지 않는다.

## 구현 경계

- 범위 계산, 리뷰 순서, 제거/복원 계산은 DOM과 분리한 순수 함수로 둬 단위 테스트한다.
- 컴포넌트는 기존 `setSelectedIds`, `applyRating`, `applyColorLabel`, `toggleExcluded`, `BridgeFullscreenPreview`를 재사용한다.
- 기존 Adobe 선택 병합, 고객 선택 불러오기, RAW 매칭 전달, 사진 분류 Scene 리뷰는 변경하지 않는다.
- `Command/Ctrl + B`는 브라우저 기본 북마크/굵게 동작을 `preventDefault()`로 막는다.

## 검증

- Shift+방향키 범위 확장·축소와 그리드 끝 동작을 단위 테스트한다.
- 리뷰 제거·LIFO 복원·순환 이동과 1장/2~4장/5장 이상 레이아웃 결정을 단위 테스트한다.
- 키보드 라우팅이 리뷰, 전체화면, 일반 그리드 순서로 처리되는지 회귀 테스트한다.
- `npm run typecheck`와 관련 Vitest를 실행한다.
- 실제 브라우저에서 넓은 폭·좁은 폭, 2장·4장·5장 이상 리뷰, 배경 분리를 확인한다.

## 범위 밖

- 서버 API, 데이터베이스, 파일 이동, RAW 매칭 알고리즘은 수정하지 않는다.
- 별점이나 제외를 선택 해제로 간주하지 않는다.
- 리뷰 결과를 별도 이름으로 저장하거나 되돌리는 새 기록 기능을 만들지 않는다.
