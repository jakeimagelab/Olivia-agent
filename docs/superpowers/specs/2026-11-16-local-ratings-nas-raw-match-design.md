# 로컬 별점 → NAS RAW 매칭 설계

## 목표

노트북의 Olivia Bridge에서 로컬 JPG에 매긴 별점·컬러와 작업 대상 선택을 그대로 사용하면서, RAW 원본은 Mac Studio가 접근하는 NAS에서 찾아 `Selected_RAW`에 복사한다. JPG/RAW 파일 본문은 Vercel을 통과하지 않는다.

## 현재 문제

로컬 Bridge에서 연 RAW 매칭은 브라우저 `File System Access API`의 폴더 핸들만 사용한다. 따라서 노트북에 NAS가 마운트되지 않은 경우 자동 탐색과 `RAW 폴더 직접 지정`이 모두 로컬 폴더만 대상으로 동작한다. 이미 존재하는 NAS RAW 매칭 경로는 Bridge 자체를 NAS 폴더로 연 경우에만 활성화되어, 로컬 JPG 셀렉과 NAS RAW를 함께 쓸 수 없다.

## 승인된 동작

1. 로컬 Bridge의 선택 사진·별점·컬러는 그대로 유지한다.
2. 자동 RAW 탐색에 실패한 화면에서 기존 로컬 선택과 함께 `NAS 촬영 폴더 선택`을 제공한다.
3. NAS 선택은 현재 Bridge 폴더를 바꾸거나 로컬 셀렉을 초기화하지 않는다.
4. 브라우저는 선택 JPG의 파일명, 상대 경로 힌트, 파일 크기, EXIF 촬영시각과 선택한 NAS 폴더 식별자만 원격 작업에 전달한다.
5. Mac Studio 워커가 선택한 NAS 폴더 아래에서 같은 파일명의 RAW 후보를 찾고, JPG·RAW 촬영시각이 2초 이내인 항목만 확정한다.
6. 확정된 RAW만 NAS 프로젝트의 `Selected_RAW` 폴더에 복사한다.
7. 이 로컬→NAS 모드에서는 로컬 JPG와 NAS JPG/XMP를 이동하지 않는다.
8. 기존 로컬 RAW 매칭과 Bridge 자체를 NAS로 연 기존 원격 RAW 매칭 동작은 그대로 보존한다.

## UI

- 기존 다크 RAW 매칭 화면과 카드 구조를 유지한다.
- 자동 탐색 실패 영역에 두 선택지를 표시한다.
  - `이 기기에서 RAW 폴더 선택`: 기존 로컬 폴더 선택
  - `NAS 촬영 폴더 선택`: 기존 NAS 폴더 탐색기를 RAW 원본 선택 용도로 연다
- 폴더 선택 버튼은 실행 버튼이 아니므로 외곽선 보조 버튼을 사용한다.
- NAS 폴더 선택 뒤에는 선택한 NAS 경로와 `Mac Studio에서 RAW를 찾아 Selected_RAW에 복사합니다.`라는 설명을 표시한다.
- Mac Studio가 꺼져 있거나 선택 정보가 부족하면 버튼 근처에 비활성 이유를 한 줄로 표시한다.
- 실행 중·완료·실패 상태는 기존 RAW 매칭 상태 영역을 재사용하며 별도의 새 패널을 만들지 않는다.

## 데이터 흐름

```text
로컬 Bridge 선택/별점
  → 선택 JPG 메타데이터 추출
  → NAS 촬영 폴더 선택
  → PHOTO_BRIDGE_RAW_MATCH 원격 작업
  → Mac Studio가 선택 NAS 경로 검증
  → RAW 인덱스 생성
  → 파일명 + 촬영시각으로 매칭
  → NAS/Selected_RAW에 속성 보존 복사
  → 결과 반환
```

기존 `PHOTO_BRIDGE_RAW_MATCH` 작업을 확장해 `copyJpg=false` 또는 동등한 명시적 모드를 전달한다. 워커는 이 모드에서 JPG/XMP 이동 계획을 만들지 않는다. 경로는 허용된 `/Volumes` 루트 내부인지 기존 검증기를 통해 확인하며, 브라우저가 임의 절대경로를 조합하지 않는다.

## 안전 규칙

- RAW 원본과 로컬 JPG는 수정·이동하지 않는다.
- 대상에 같은 이름의 파일이 있으면 기존 속성 검증 규칙에 따라 재사용하거나 충돌로 보고하며 덮어쓰지 않는다.
- 촬영시각이 없거나 후보가 여러 개로 확정되지 않으면 복사하지 않고 확인 필요로 남긴다.
- NAS 선택이 취소되거나 워커가 연결되지 않았으면 기존 로컬 작업 상태에 영향을 주지 않는다.
- NFC/NFD와 SMB 재마운트 이름은 기존 NAS 경로 해석기를 재사용한다.

## 검증

- 로컬 Bridge 선택 63장이 NAS 폴더 선택 뒤에도 유지된다.
- 로컬 별점/컬러 기준 결과와 원격 작업 대상 수가 같다.
- NAS RAW 후보가 파일명과 촬영시각을 만족할 때 `Selected_RAW`에 복사된다.
- 로컬 JPG 및 NAS JPG/XMP는 이동·수정되지 않는다.
- 워커 오프라인, NAS 폴더 미발견, 촬영시각 불일치가 각각 이해 가능한 실패 상태로 표시된다.
- 기존 로컬 RAW 폴더 직접 지정과 기존 NAS Bridge RAW 매칭 회귀 테스트가 통과한다.
- `npx tsc --noEmit`과 관련 Vitest를 통과한다.

## 범위 밖

- 로컬 JPG 파일을 NAS로 업로드하거나 동기화하는 기능
- 로컬 Adobe Bridge 캐시 자체를 읽는 기능(파일에 기록된 별점·컬러만 사용)
- 이 모드에서 JPG/XMP를 `N차보정본`으로 이동하는 기능
