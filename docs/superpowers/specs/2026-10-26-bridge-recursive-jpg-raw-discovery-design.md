# Olivia Bridge 하위 JPG 보기와 RAW 폴더 자동 탐색 설계

작성일: 2026-10-26

## 목적

Bridge에서 선택한 촬영 폴더의 하위 JPG를 한 화면에서 확인하고 셀렉할 수 있게 한다. 셀렉 결과를 RAW 매칭으로 넘길 때에는 사용자가 폴더를 다시 찾지 않아도 현재 폴더와 상위 1·2단계 안에서 RAW 위치를 빠르게 발견한다.

## 범위

- Bridge 폴더 패널에 `하위 폴더 JPG 포함` 체크를 추가한다.
- 체크가 꺼져 있으면 현재처럼 현재 폴더 파일만 표시한다.
- 체크가 켜져 있으면 최대 5단계 하위 폴더의 JPG를 현재 썸네일 목록에 합친다.
- 하위 JPG에는 현재 폴더 기준 상대 경로를 표시한다.
- RAW와 사이드카 표시는 현재 폴더 기준을 유지한다.
- JPG 정리 도구의 기존 `하위 폴더까지 모두 처리`와 안전한 이동 로직은 변경하지 않는다.
- RAW 매칭은 현재 폴더, 상위 1단계, 상위 2단계까지만 자동 탐색한다.

## 하위 JPG 탐색

`scanBridgeFolder`에 하위 JPG 포함 옵션을 추가한다. 첫 단계에서는 기존처럼 현재 폴더의 폴더·JPG·RAW·사이드카를 읽는다. 옵션이 켜진 경우에만 하위 디렉터리를 최대 5단계까지 방문하며 JPG만 추가한다.

각 JPG 항목에는 현재 폴더 기준 `relativePath`를 기록한다. 파일 ID에는 상대 경로를 포함해 다른 하위 폴더에 같은 파일명이 있어도 선택 상태와 썸네일 캐시가 충돌하지 않게 한다.

토글 전환 시 다음 상태를 새 스캔 결과에 맞춘다.

- 현재 선택
- 포커스와 미리보기
- 레이블·별점·제외 상태
- Scene 백그라운드 분석
- 사진 도구에 전달되는 선택 파일

하위 JPG가 포함된 경우 중앙 머리글에 전체 JPG 수와 하위 폴더에서 추가된 JPG 수를 함께 표시한다.

## RAW 폴더 자동 탐색

Bridge는 브라우저가 이미 권한을 가진 breadcrumb 핸들만 사용한다. 후보는 다음 순서다.

1. 현재 폴더
2. 상위 1단계
3. 상위 2단계

선택 JPG 목록에서 앞쪽의 서로 다른 basename 1~2개를 대표 표본으로 사용한다. 각 후보 폴더에서 표본과 같은 basename의 RAW 확장자를 직접 확인하고, 필요할 때만 기존 재귀 RAW 인덱스를 사용한다.

- 표본이 모두 발견되면 해당 후보를 즉시 채택한다.
- 일부만 발견되면 세 후보 중 발견 수가 가장 많은 폴더를 채택한다.
- 동률이면 현재 위치에 더 가까운 후보를 채택한다.
- 하나도 발견하지 못하면 자동 선택하지 않고 기존 `다른 RAW 폴더 선택`을 안내한다.

자동 발견은 폴더 제안과 사전 확인까지만 수행한다. RAW 복사·이동은 기존 실행 버튼을 누르기 전에는 시작하지 않는다.

RAW 매칭 화면에는 다음 상태를 표시한다.

- `RAW 폴더를 자동으로 찾는 중입니다`
- `촬영본 폴더 자동 발견 · 표본 2/2개 확인`
- `자동으로 찾지 못했습니다. RAW 폴더를 선택해 주세요.`

자동 발견 뒤에는 기존 전체 선택 목록으로 preflight를 실행해 최종 매칭·누락 수를 보여준다. 사용자는 언제든 `다른 RAW 폴더 선택`으로 결과를 바꿀 수 있다.

## 성능과 안전

- 하위 JPG 스캔은 토글이 켜졌을 때만 실행한다.
- JPG 파일 메타데이터 읽기는 기존 제한 병렬 처리를 유지한다.
- RAW 탐색은 전체 목록보다 대표 basename 1~2개를 먼저 검사한다.
- 기존 RAW 재귀 스캔의 제외 폴더, 최대 깊이, 원본 보존, 복사·이동 확인 로직을 유지한다.
- 브라우저 권한 밖의 상위 폴더는 임의로 접근하지 않는다.

## UI

- 토글은 왼쪽 폴더 패널의 현재 폴더와 하위 폴더 목록 사이에 둔다.
- 어두운 Bridge 패널의 기존 보조 체크 표현을 재사용한다.
- 새 탭이나 주 실행 버튼은 만들지 않는다.
- 썸네일 상대 경로는 파일명 아래 흐린 한 줄로 표시한다.
- 좁은 창에서도 폴더 패널과 썸네일 카드가 가로 넘침을 만들지 않는다.

## 오류 처리

- 읽을 수 없는 하위 폴더는 전체 스캔을 중단하지 않고 오류 개수로 알린다.
- 토글 재스캔 실패 시 기존 스캔 결과를 유지하고 오류 문장을 표시한다.
- RAW 자동 탐색 실패는 직접 폴더 선택으로 복구할 수 있게 한다.

## 검증

- 토글을 끄면 현재 폴더 JPG만 보인다.
- 토글을 켜면 최대 5단계 하위 JPG가 상대 경로와 함께 보인다.
- 같은 파일명이 서로 다른 하위 폴더에 있어도 각각 선택된다.
- 토글을 다시 끄면 하위 JPG 선택과 미리보기가 제거된다.
- JPG 정리 미리보기와 실행은 기존 하위 폴더 처리 범위를 유지한다.
- 현재·상위 1·상위 2단계의 RAW 표본 발견을 각각 테스트한다.
- 표본 1~2개 탐색 뒤 전체 선택 목록 preflight가 실행된다.
- RAW 자동 발견 실패 시 직접 선택이 계속 동작한다.
- 타입 검사, 린트, 관련 Vitest, 프로덕션 빌드를 실행한다.
