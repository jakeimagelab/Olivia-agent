# 콘티 AI 장면 추가 설계

## 목표

- 결과 표의 `장면 추가`를 누르면 현재 진료과에 맞는 추천 장면을 먼저 보여준다.
- 추천은 기존 장면과 겹치지 않아야 하며 장면명, 설명, 장소, 인물, 소요시간, 사진·영상 값을 포함한다.
- AI 호출이 실패해도 진료과 taxonomy의 기본 추천으로 작업을 계속할 수 있어야 한다.
- 기존 빈 장면 추가 기능은 팝업 안의 보조 동작으로 유지한다.

## 사용자 흐름

1. 결과 표 하단의 `장면 추가`를 누른다.
2. 닫기 `X`가 있는 밝은 팝업이 열리고 추천 장면을 불러온다.
3. 추천 행을 복수 선택하고 `선택한 장면 추가`를 누른다.
4. 선택한 장면을 순서대로 저장한 뒤 표 끝에 표시한다.
5. 직접 작성하려면 `빈 장면 추가`를 누른다.

## 추천 규칙

- 서버가 `conti_runs.specialty`, 의료진 명단, 기존 장면명을 직접 읽는다.
- AI에는 현재 진료과와 기존 장면만 전달하며 기존 장면과 같은 추천은 제거한다.
- 마취통증의학과는 C-ARM 신경차단술, 초음파 주사치료, 통증 진찰, 영상 판독, 시술 전 상담을 기본 후보로 둔다.
- AI 키 누락, 응답 오류, 시간 초과 시 코드 기반 후보를 반환하고 화면에 기본 추천임을 알린다.

## 저장

- 기존 `POST /api/conti/scenes`를 확장해 추천 장면의 허용 필드만 받는다.
- 클라이언트가 보낸 run의 진료과 정보는 신뢰하지 않는다.
- 장면은 한 건씩 순서대로 저장해 sort와 scene_code가 겹치지 않게 한다.
- 구형 DB에서 지원하지 않는 선택 컬럼은 기존 스키마 호환 저장 경로로 처리한다.

## 오류와 접근성

- 추천 실패는 팝업 안에 이유와 `다시 추천` 버튼을 표시한다.
- 팝업은 `role="dialog"`, `aria-modal="true"`, 닫기 44px 터치 영역을 사용한다.
- 선택하지 않았을 때 실행 버튼은 외곽선형 비활성 상태이며 이유를 한 줄 표시한다.
- 글자 굵기는 600 이하, 주 실행은 `#C94A1E`, 보조는 `#155855` 외곽선을 사용한다.

## 검증

- 마취통증의학과 기본 추천에 진료과 관련 장면이 포함되는지 확인한다.
- 기존 장면과 이름이 겹치는 후보가 제외되는지 확인한다.
- AI 실패 시 기본 추천이 반환되는지 확인한다.
- 선택 추천과 빈 장면이 모두 저장되는지 확인한다.
- 데스크톱과 좁은 화면에서 팝업과 닫기 버튼을 확인한다.
