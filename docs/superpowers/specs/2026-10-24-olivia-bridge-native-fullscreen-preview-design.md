# Olivia Bridge OS 창 미리보기·레이블 설계

작성일: 2026-10-24

## 목적

Olivia Bridge에서 JPG를 보고 있을 때 Space를 누르면 브라우저나 macOS 자체 전체화면으로 빠지지 않고, Olivia OS의 Bridge 창 안을 채우는 사진 미리보기를 연다. 일반 화면과 이 미리보기에서 같은 별점·컬러 레이블 단축키를 쓴다.

## 확정 동작

- 선택된 JPG가 있을 때 Space를 누르면 Bridge 루트 안의 미리보기 오버레이를 연다.
- Space를 다시 누르거나 Esc 또는 우측 상단 X를 누르면 미리보기를 닫는다.
- 미리보기에서도 왼쪽·오른쪽 방향키로 이전·다음 JPG를 볼 수 있다.
- `1`~`5`는 별점, `0`은 별점 초기화다.
- `6`은 빨강, `7`은 노랑, `8`은 초록, `9`는 파랑 컬러 레이블이다.
- 현재 컬러와 같은 숫자를 다시 누르면 컬러만 해제한다.
- 별점과 컬러 레이블은 독립된 값이라 한 사진에 동시에 유지된다.
- 전체화면 미리보기에서 단축키는 현재 보고 있는 JPG 한 장에 적용한다.
- 일반 화면에서 여러 JPG를 선택했으면 별점과 컬러 레이블을 선택된 JPG 전체에 적용한다.
- 기존 `별점` 필터는 유지하고, 별점 또는 컬러가 있는 JPG를 모아 보는 `레이블 있음` 필터를 추가한다.

## 저장과 호환

기존 폴더별 `localStorage` 키 `olivia-bridge:marks:{folderPath}`를 그대로 사용한다. 저장 객체의 기존 `ratings`, `excluded`를 보존하고 `colorLabels`만 추가한다. 예전 저장 객체에 `colorLabels`가 없으면 빈 객체로 읽는다. 실제 JPG·RAW·XMP 파일에는 쓰지 않는다.

## UI

- 배경: 중성 회색 `#2A2A2A`, 그라데이션 없음
- 사진: 가용 영역 안에서 원본 비율을 유지하고 `object-fit: contain`
- 하단 정보: 파일명, 현재 순서, 별점, 컬러 레이블, 단축키 안내
- 썸네일: 별점 배지와 컬러 점을 각각 표시해 두 값이 동시에 보이게 한다.
- 닫기·이동 버튼: 흰색 저채도 외곽선, 최소 터치 영역 44px
- 브라우저 Fullscreen API는 호출하지 않는다.

## 구현 구조

1. 레이블 키 정의·정규화·토글 계산은 `lib/photo-bridge/labels.ts`의 순수 함수로 둔다.
2. `OliviaBridgeWorkspace`는 폴더별 별점·컬러·제외 상태와 필터를 관리한다.
3. Space는 `fullscreenPreviewOpen` 상태만 바꾼다. 오버레이는 Bridge 루트의 절대 위치 레이어로 렌더한다.
4. 일반 화면 단축키는 선택된 JPG를, 미리보기 단축키는 현재 JPG를 대상으로 한다.
5. 표시·필터·저장은 동일한 상태를 읽으므로 즉시 같은 결과를 보여준다.

## 보존 범위

- 폴더, 현재 사진, 다중 선택, 제외 표시, Scene 분석, 사진작업실 도구 팝업은 유지한다.
- 오른쪽 고정 미리보기와 드래그 영역 선택을 유지한다.
- RAW·사이드카는 레이블 대상과 `레이블 있음` 필터 대상에서 제외한다.
- 기존 `/photo-sorting` 호환 경로와 Olivia OS 앱 등록은 바꾸지 않는다.

## 검증

- Space 미리보기가 `requestFullscreen`, `exitFullscreen`, `fullscreenchange`를 사용하지 않는다.
- 미리보기에서 `1`~`5`, `0`, `6`~`9`, 같은 컬러 키 재입력이 동작한다.
- 별점과 컬러가 동시에 저장·표시된다.
- 예전 `ratings`·`excluded` 저장 객체를 그대로 읽는다.
- `레이블 있음` 필터가 별점 또는 컬러가 있는 JPG의 합집합을 보여준다.
- 세로·가로 사진 모두 잘리지 않고 Bridge 창 안에 들어온다.
- 관련 테스트, 타입 검사, 린트, 빌드를 실행한다.
