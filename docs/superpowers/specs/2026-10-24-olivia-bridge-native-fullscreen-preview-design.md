# Olivia Bridge macOS 전체화면 미리보기 설계

작성일: 2026-10-24

## 목적

Olivia Bridge에서 JPG를 보고 있을 때 Space를 누르면 브라우저 창 안의 확대 패널이 아니라 macOS 화면 전체를 쓰는 사진 미리보기를 연다. 사진 판단에 방해되는 다른 UI는 숨기고, 세로·가로 사진 모두 잘리지 않게 한 화면에 맞춘다.

## 확정 동작

- 선택된 JPG가 있을 때 Space를 누르면 Bridge 루트 요소에 Fullscreen API를 호출한다.
- 전체화면에서는 사진만 중성 회색 `#2A2A2A` 위에 표시한다.
- 사진은 원본 비율을 유지하고 `object-fit: contain`으로 화면 안에 최대한 크게 맞춘다.
- Space를 다시 누르거나 Esc 또는 우측 상단 X를 누르면 전체화면을 닫는다.
- 전체화면에서도 왼쪽·오른쪽 방향키로 이전·다음 JPG를 볼 수 있다.
- 전체화면 진입과 종료는 폴더, 현재 사진, 다중 선택, 별점, 제외 표시를 바꾸지 않는다.
- Space의 기존 선택 토글 동작은 제거하고, 하단 단축키 안내를 `Space 전체화면`으로 바꾼다.
- JPG가 선택되지 않았거나 입력창에 포커스가 있으면 Space로 전체화면을 열지 않는다.

## 구현 구조

`OliviaBridgeWorkspace`가 전체화면 미리보기 열림 상태와 Fullscreen API 수명주기를 관리한다.

1. Space 키 이벤트에서 현재 JPG 존재 여부를 확인한다.
2. 열기 상태를 설정하고 Bridge 루트의 `requestFullscreen()`을 호출한다.
3. 루트 안의 전체화면 레이어가 기존 `BridgePreviewImage`를 재사용해 현재 JPG를 표시한다.
4. `fullscreenchange` 이벤트에서 브라우저나 macOS가 전체화면을 종료한 경우 레이어 상태도 해제한다.
5. 닫기 동작은 `document.exitFullscreen()`을 사용한다.

Fullscreen API가 거절되면 전체화면 레이어 상태를 즉시 되돌리고 기존 Bridge 화면을 유지한다. 파일, 선택, 평가 상태는 변경하지 않는다.

## UI

- 배경: `#2A2A2A`, 그라데이션 없음
- 사진: 화면 전체 가용 영역, `max-width: 100%`, `max-height: 100%`, `object-fit: contain`
- 닫기와 이동 버튼: 흰색 저채도 외곽선의 보조 조작, 최소 터치 영역 44px
- 별도 제목, 파일 정보 카드, 채운 실행 버튼은 추가하지 않는다.
- 닫기·이동 조작은 사진을 가리지 않도록 가장자리에 배치한다.

## 보존 범위

- 오른쪽 고정 미리보기는 그대로 유지한다.
- 마우스 클릭, Command 클릭, Shift 범위 선택은 그대로 유지한다.
- 별점, 제외 표시, Scene 분석, 사진작업실 도구 팝업과 파일 처리 로직은 바꾸지 않는다.
- 기존 `/photo-sorting` 호환 경로와 Olivia OS 앱 등록은 바꾸지 않는다.

## 검증

- 선택된 JPG에서 Space를 누르면 `document.fullscreenElement`가 Bridge 루트가 된다.
- 세로·가로 사진 모두 잘리지 않고 화면 안에 들어온다.
- 전체화면에서 ← → 이동, Space 닫기, Esc 닫기, X 닫기가 동작한다.
- 전체화면을 닫은 뒤 폴더와 선택·별점·제외 상태가 유지된다.
- 입력창 포커스와 JPG 미선택 상태에서는 Space가 전체화면을 열지 않는다.
- 관련 테스트, 타입 검사, 린트, 빌드를 실행한다.
