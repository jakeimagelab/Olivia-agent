# 사진 작업실 안전 이름변경 설계

## 목적

사진 작업실의 현재 로컬 작업 폴더를 대상으로 사진 파일 이름만 안전하게 바꾼다. 파일 바이트와 EXIF, ICC, 픽셀 데이터는 변경하지 않는다.

## 범위

- 사진 작업실 탭 순서를 `사진 셀렉 → RAW 매칭 → 사진 분류 → T컷 정리 → 사진 리사이즈 → 이름변경 → 사진 보정`으로 정렬한다.
- 로컬 작업 폴더 핸들을 사진 작업실 공용 컨텍스트에 유지한다. 기존 도구가 선택한 폴더를 이름변경 탭이 사용하며, 이름변경에는 원본 폴더 선택 UI가 없다.
- 이름 규칙은 일반 시퀀스, 직속 부모 폴더 prefix, 직접 입력 prefix 세 가지다.
- 이동/복사 목적지는 사용자가 선택한 경우에만 사용한다. 같은 폴더 방식은 기본값이다.

## 구조

`lib/photoRename/`은 파일 탐색, 안정 정렬, 새 이름 생성, prefix 중복 방지, preflight 상태 계산을 담당한다. UI와 독립된 계획(plan)이 미리보기와 실행에 동일하게 사용되므로 시퀀스 순서가 바뀌지 않는다.

기존 `lib/metadataSelect/fileOperations.ts`의 안전 전송기를 목적지 이름을 별도로 받을 수 있게 확장한다. 이 전송기는 모든 대상의 복사와 size/SHA-256 검증을 먼저 끝내고, 그 뒤에만 원본을 삭제한다. 실패하면 새 복사본을 정리하고 원본을 유지한다.

## 안전 규칙

- 직접 `rename()` 하지 않는다.
- 파일 하나의 원본/생성본 SHA-256과 size가 모두 같을 때만 검증 성공이다.
- 배치 전체 COPY & VERIFY가 완료되기 전에는 원본을 하나도 삭제하지 않는다.
- 대상끼리, 기존 대상 폴더와, 대소문자/NFC 기준의 이름 충돌은 실행 전에 `DUPLICATE`로 표시하고 실행을 막는다.
- 부모/사용자 prefix가 이미 파일명 앞에 있으면 `SKIP`한다.

## UI

기존 사진 작업실의 딥그린 작업 패널과 우측 가이드를 재사용한다. 첨부 시안과 같이 처리 방식, 이름 변경 방식, 해당 옵션, 하위 폴더 옵션, 상태 요약과 기존→변경 파일명 미리보기를 한 화면에 둔다. 복사와 이동 목적지 선택은 해당 방식일 때만 보인다.

## 검증

순수 이름 규칙과 preflight에는 Vitest를 추가한다. 안전 전송기에는 SHA-256 일치, 불일치 롤백, 같은 폴더 rename, destination 충돌 테스트를 추가한다. 기존 사진·RAW·메타데이터 테스트와 typecheck/build도 실행한다.
