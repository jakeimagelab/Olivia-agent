# Bridge 검색·셀렉 필터 단축키 설계

## 범위

관리자 Olivia Bridge와 고객 셀렉 Bridge에 동일한 파일명 검색과 별점·컬러 교차 필터를 추가한다. DB, 선택 저장 방식, 리뷰, 전체화면, 폴더 탐색은 변경하지 않는다.

## 공용 로직

- `lib/photo-bridge/labels.ts`가 파일명 검색어 정규화, 부분 일치, 복합 셀렉 필터 상태, 필터 토글, 별점 이상·컬러 일치 판정을 담당한다.
- 검색어는 NFC 정규화 후 소문자로 비교하고 쉼표 또는 공백으로 나눈 토큰 중 하나라도 파일명에 포함되면 통과한다.
- 필터 상태는 별점과 컬러를 독립 보관한다. 두 조건이 모두 있으면 AND로 판정하며 별점은 Adobe Bridge 방식처럼 지정 점수 이상이다.
- 공용 React 훅은 `⌘/Ctrl+F`, `Esc`, `⌥+⌘/Ctrl+1~9`, `⌥+⌘/Ctrl+A`를 해석한다. 입력 요소에서는 검색창의 Esc 이외 단축키를 처리하지 않는다.

## 화면 연결

- 두 화면의 사진 그리드 제목 줄 오른쪽, 썸네일 크기 조작 앞에 같은 검색 컨트롤을 둔다.
- 검색은 현재 폴더와 이미 활성화된 파일·고객·AI 필터 결과에 추가 적용한다.
- 활성 별점·컬러 조건은 각각 제거 가능한 칩으로 표시한다.
- 관리자 Bridge의 RAW·사이드카는 사진 검색 중 숨기고, 검색을 지우면 기존 필터 상태대로 복구한다.
- 고객 Bridge는 서버가 확인한 별점·컬러를 기준으로 필터링한다. 작업 대상과 저장 대기 상태는 필터 계산에 사용하지 않는다.

## 잘림 방지

- 왼쪽 패널은 제목, 스크롤 가능한 폴더·필터 본문, 고정 통계, 선택적인 썸네일 크기 영역으로 나눈다.
- 오른쪽 고객 미리보기는 높이가 부족할 때 패널 내부에서 스크롤할 수 있게 하고, 모바일 하단 바는 safe-area를 포함한다.
- 중앙 단축키 줄은 고정 높이를 강제하지 않고 가로 스크롤로 모든 안내를 읽을 수 있게 한다.

## 검증

- 검색 토큰·NFC·대소문자 무시, 복합 필터 토글, 별점 이상 판정을 단위 테스트한다.
- 두 컴포넌트가 공용 훅과 공용 판정 함수를 사용하는지 회귀 테스트한다.
- 타입 검사와 관련 Vitest를 실행하고, 높이 800px 데스크톱 및 모바일 화면을 실제 렌더링해 통계·하단 바 잘림을 확인한다.
