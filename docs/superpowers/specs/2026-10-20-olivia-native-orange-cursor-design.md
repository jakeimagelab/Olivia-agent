# Olivia 네이티브 오렌지 커서 설계

## 목적

Olivia OS에서 현재 DOM 요소로 그리는 오렌지 원형 커서가 실제 마우스보다 늦게 따라오는 문제를 없앤다. 기존 12px 채운 오렌지 원 모양과 입력·드래그 영역의 시스템 커서는 유지한다.

## 원인

현재 `CursorEffect`는 시스템 커서를 숨기고 `mousemove`마다 DOM 요소의 `transform`을 갱신한다. 가리키는 요소가 바뀔 때는 `elementFromPoint`, 전역 클래스 토글, `getComputedStyle`까지 실행한다. 따라서 하드웨어 커서보다 렌더링 프레임이 늦고 요소 경계에서 추가 스타일 계산이 발생한다.

## 적용 방식

- DOM 원과 좌표 추적 이벤트를 제거한다.
- 12px 채운 오렌지 원을 CSS `cursor: url(...)` 네이티브 커서로 적용한다.
- 핫스팟은 원 중심에 둔다.
- 클릭 중에는 기존과 같이 더 짙은 오렌지로 바꾸되, 좌표는 추적하지 않는다.
- `input`, `textarea`, `select`, 편집 가능 영역, `canvas`, 드래그 대상은 기존 시스템 커서를 유지한다.
- 터치 기기와 공개 고객 포털의 현재 제외 범위는 유지한다.

## 수정 범위

- `components/CursorEffect.tsx`: 경로·포인터 종류에 따른 클래스 적용과 클릭 상태만 담당한다.
- `app/globals.css`: 네이티브 오렌지 원 커서와 시스템 커서 예외를 정의한다.

데이터, API, 창 동작, 클릭 처리 및 다른 화면 스타일은 변경하지 않는다.

## 검증

- Olivia OS에서 원이 실제 포인터와 동시에 움직이는지 확인한다.
- 버튼과 일반 영역에서 12px 오렌지 원이 보이는지 확인한다.
- 입력칸은 텍스트 커서, 드래그 영역은 해당 시스템 커서를 유지하는지 확인한다.
- 터치 환경과 고객 포털에 커서 효과가 생기지 않는지 확인한다.
- 타입 검사와 린트를 실행한다.
