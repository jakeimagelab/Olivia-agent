# 홈 채팅 높이와 배경 출처 표시 정리

## 목표

- 홈 화면 아래 채팅 입력 영역의 세로 높이를 줄여 본문과 배경사진에 더 많은 공간을 준다.
- 홈 왼쪽 아래에 노출되던 최근 완료 촬영의 병원명·촬영일 표시는 제거한다.

## 변경 범위

- 데스크톱 홈 채팅 슬롯 높이: `128px` → `104px`
- 채팅 입력창 최소 높이: `84px` → `64px`
- 전송 버튼: `50px` → `42px`
- `HomeChat`의 `homePhotoCredit` 렌더와 CSS 제거
- 900px 이하 화면의 기존 `74px` 입력 높이는 유지

## 보존 범위

- 최근 완료 촬영 썸네일을 홈 배경으로 쓰는 데이터 조회와 선택 로직
- 홈 채팅 대화, 제안 버튼, 전송 동작
- 오늘 요약, 내 차례 목록, 모바일 레이아웃

## 검증

- 소스 회귀 테스트로 병원명 표시 제거와 데스크톱/모바일 높이 규칙 확인
- 타입 검사와 대상 파일 린트
- 데스크톱 홈 화면에서 입력창 높이와 왼쪽 아래 문구 제거 확인
