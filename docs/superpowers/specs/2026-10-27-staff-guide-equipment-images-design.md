# 스텝 가이드 장비 이미지 설계

작성일: 2026-10-27

## 목표

사용자가 제공한 장비 안내 이미지 10장을 기존 `스텝 가이드` 안에서 읽기 쉽게 제공한다. Olivia OS 창과 공개 `/staff-guide` 페이지에서 같은 컴포넌트를 사용하며, 기존 장비 규칙·DB·체크리스트 동작은 변경하지 않는다.

## 배치와 동작

- 기존 `촬영 종류별 세팅` 다음, `챙길 장비` 전에 `장비 사진` 섹션을 추가한다.
- 카메라, 렌즈, 조명, A스탠드, 삼각대·슬라이더, 짐벌, 배경세트, 동조기, 배터리, 저장장치·기타의 10개 카테고리를 제공한다.
- 상단의 카테고리 선택 버튼과 이전·다음 버튼으로 한 장씩 전환한다.
- 선택한 이미지 한 장만 큰 크기로 표시한다. 이미지 안의 글자가 읽히도록 2열 썸네일 그리드는 사용하지 않는다.
- 이미지는 원본 비율을 유지하고 `width: 100%`, `height: auto`, `object-fit: contain`으로 표시한다.
- 첫 이미지만 우선 표시하고 나머지는 선택될 때 불러온다. 이전·다음 이미지는 브라우저가 자연스럽게 캐시한다.
- 키보드 포커스, `aria-pressed`, 이미지 대체 텍스트, 이전·다음 버튼의 접근 가능한 이름을 제공한다.

## 에셋

- 제공된 941×1672 PNG 원본 10장을 `public/assets/staff-guide/equipment/` 아래에 의미가 드러나는 영문 파일명으로 복사한다.
- 원본 파일의 내용, 비율, 문구는 수정하지 않는다.
- 브라우저에는 정적 경로로 제공하고 외부 저장소나 새 API를 추가하지 않는다.

## UI 규칙

- 스텝 가이드는 밝은 정보 화면이므로 기존 `#FDFCFA` 바탕과 흰 카드를 유지한다.
- 선택 버튼은 기존 가이드의 선택 칩 시각 언어를 재사용한다. 새로운 탭 단계나 채운 주 실행 버튼을 만들지 않는다.
- 제목 굵기는 600 이하로 유지한다.
- 좁은 화면에서는 카테고리 선택 줄을 가로 스크롤할 수 있게 하고 페이지 자체에는 가로 스크롤이 생기지 않게 한다.
- Olivia OS 기본 창 너비 560px와 모바일 390px에서 이미지와 조작부가 카드 안에 맞아야 한다.

## 변경 범위

- `components/staff-guide/StaffGuide.tsx`: 이미지 목록과 선택 상태, 장비 사진 섹션을 추가한다.
- `components/staff-guide/StaffGuide.module.css`: 선택 줄, 이미지 프레임, 이전·다음 조작의 반응형 스타일을 추가한다.
- `public/assets/staff-guide/equipment/`: 사용자 제공 이미지 10장을 추가한다.
- 필요한 경우 이미지 목록의 순서와 경로를 검증하는 단위 테스트를 추가한다.

다음 항목은 변경하지 않는다.

- `lib/shootSetup/rules.ts`의 장비 배정 규칙
- 장비 DB와 장비 API
- `pc-staff-guide-v1` 체크 상태 저장 방식
- Olivia OS 앱 등록, 공개 페이지 권한, 현장뷰 링크

## 오류와 빈 상태

- 정적 이미지가 로드되지 않으면 깨진 이미지 아이콘에만 의존하지 않고 해당 카테고리 이름을 대체 텍스트로 제공한다.
- 이미지 선택 상태는 컴포넌트 내부 상태이므로 서버 데이터 조회 실패와 독립적으로 동작한다.

## 검증

- `npm run typecheck`
- 관련 린트 또는 `npm run lint`
- 관련 단위 테스트
- 공개 `/staff-guide`와 Olivia OS 스텝 가이드 창에서 카테고리 10개 전환 확인
- 390px와 560px 폭에서 가로 스크롤과 이미지 잘림 여부 확인
- 기존 장비 체크 저장·초기화 동작 회귀 확인
