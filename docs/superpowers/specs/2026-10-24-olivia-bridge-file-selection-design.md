# Olivia Bridge 파일 선택 규칙

## 목적

Olivia Bridge의 JPG 썸네일 선택 방식을 데스크톱 파일 브라우저의 기본 규칙과 같게 만든다. 선택 결과는 기존 사진 셀렉·RAW 매칭·분류·리사이즈 등 Bridge 내부 도구에 그대로 전달한다.

## 범위

- JPG 썸네일만 선택 대상이다.
- RAW와 XMP 등 사이드카는 기존처럼 파일 형식과 이름만 표시한다.
- 파일 처리, 레이블 저장, 필터, 도구 실행 방식은 바꾸지 않는다.

## 선택 동작

- JPG 클릭: 기존 선택을 지우고 클릭한 한 장만 선택한다.
- 빈 영역 클릭: 현재 선택을 모두 해제한다.
- `Command` 또는 `Control`을 누른 채 JPG 클릭: 클릭한 한 장을 기존 선택에 추가하거나 선택에서 뺀다.
- `Shift`를 누른 채 JPG 클릭: 마지막 기준 사진부터 클릭한 사진까지의 연속 범위로 선택을 교체한다.
- `Command` 또는 `Control`과 `Shift`를 함께 누른 채 JPG 클릭: 기존 선택에 연속 범위를 추가한다.
- 일반 드래그: 선택 사각형에 닿은 JPG 전체로 선택을 교체한다.
- `Command`, `Control`, 또는 `Shift`를 누른 채 드래그: 기존 선택에 선택 사각형의 JPG를 추가한다.
- 드래그가 끝난 직후 발생하는 클릭 이벤트는 무시해 영역 선택이 한 장 선택으로 덮이지 않게 한다.

## 초점과 미리보기

- 클릭한 JPG를 키보드 초점과 오른쪽 미리보기 대상으로 삼는다.
- 범위 선택에서도 마지막으로 클릭한 JPG를 미리보기 대상으로 삼는다.
- 영역 선택 후에는 화면 순서상 첫 번째로 선택된 JPG를 미리보기 대상으로 삼는다.
- 선택이 비어 있으면 미리보기도 비운다.

## 구현 경계

- 단일·추가·범위 선택 계산은 기존 `updateBridgeSelection`을 유지한다.
- 영역 선택 계산은 기존 `bridgeMarqueeSelection`을 확장해 `Shift`도 추가 선택 수정자로 취급한다.
- 포인터 이동 임계값과 선택 사각형 렌더링은 기존 동작을 유지한다.
- 빈 영역 클릭과 썸네일 클릭이 충돌하지 않도록 이벤트 대상을 구분한다.

## 검증

- 단일 클릭, 빈 영역 클릭, `Command`/`Control` 토글, `Shift` 범위, 복합 수정자 범위를 단위 테스트한다.
- 일반 드래그가 기존 선택을 교체하는지 확인한다.
- `Command`/`Control`/`Shift` 드래그가 기존 선택에 추가하는지 확인한다.
- 드래그 직후 클릭 억제와 오른쪽 미리보기 대상을 브라우저에서 확인한다.
- 타입 검사, lint, 관련 Vitest, 전체 테스트, build를 실행한다.
