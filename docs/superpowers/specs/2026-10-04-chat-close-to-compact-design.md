# 채팅창 닫기 버튼의 한 줄 축소 동작

## 목표

Olivia 데스크톱 채팅창의 빨간 닫기 버튼을 누르면 창을 제거하지 않고, 현재 구현된 한 줄 입력 상태로 접는다. 사용자는 대화 세션을 유지한 채 화면을 비우고 즉시 새 메시지를 입력할 수 있어야 한다.

## 동작

- `olivia-chat` 창의 빨간 버튼은 `chatCompact` 상태를 `true`로 바꾼다.
- 같은 창과 같은 `OliviaConversation`을 계속 렌더링한다.
- 한 줄 상태에서는 기존 `AppWindow.module.css`의 compact composer UI를 그대로 사용한다.
- 노란 버튼은 기존 Dock 최소화 동작을 유지한다.
- 초록 버튼은 기존 최대화/복원 동작을 유지한다.
- Dock 채팅 아이콘과 상단 채팅 기능 아이콘의 기존 전체 창 복원 동작을 유지한다.
- 일반 앱의 빨간 버튼은 기존 창 닫기 동작을 유지한다.

## 구현 범위

- `components/olivia-os/window/AppWindow.tsx`에서 채팅창 전용 닫기 콜백을 연결한다.
- 기존 `useOliviaDesktopUtilityStore`와 `chatCompact` 상태를 재사용한다.
- 새 채팅 컴포넌트, 새 대화 저장소, 새 API는 만들지 않는다.
- 필요하면 기존 데스크톱 편의기능 테스트에 빨간 버튼 연결 회귀 검증만 추가한다.

## 접근성과 오류 처리

- 빨간 버튼의 기존 `aria-label="닫기"`는 유지한다. 시각적으로는 macOS 창 닫기 버튼이지만 채팅에서는 안전한 축소 동작을 수행한다.
- 축소는 로컬 UI 상태 변경이므로 별도 네트워크 오류 경로는 없다.
- 채팅창 인스턴스가 이미 사라진 경우 콜백이 실행될 수 없으므로 추가 예외 처리는 필요하지 않다.

## 검증

1. 일반 상태에서 채팅창 빨간 버튼을 누르면 한 줄 입력창으로 바뀐다.
2. 같은 대화 메시지와 작성 경로가 유지된다.
3. 노란 버튼은 Dock 최소화, 초록 버튼은 최대화로 계속 동작한다.
4. 다른 앱의 빨간 버튼은 실제 창 닫기로 계속 동작한다.
5. Dock 채팅 아이콘으로 전체 채팅창이 복원된다.
6. 타입 검사와 관련 단위 테스트가 통과한다.
