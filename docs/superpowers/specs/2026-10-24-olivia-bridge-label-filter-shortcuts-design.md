# Olivia Bridge 레이블 필터 단축키 설계

작성일: 2026-10-24

## 목적

Adobe Bridge와 비슷하게 키보드만으로 특정 별점 또는 컬러 레이블의 JPG를 빠르게 걸러 본다. 기존 레이블 지정, 마우스 선택, 파일 필터, RAW·사이드카 표시는 보존한다.

## 단축키

- `Option + Command + 1–5`: 입력한 숫자와 정확히 같은 별점의 JPG만 표시한다.
- `Option + Command + 6–9`: 입력한 숫자에 대응하는 컬러 레이블의 JPG만 표시한다.
  - `6`: 빨강
  - `7`: 노랑
  - `8`: 초록
  - `9`: 파랑
- `Option + Command + A`: 정밀 레이블 필터를 해제하고 JPG·RAW·사이드카를 포함한 기존 `모든 파일` 보기로 돌아간다.
- 같은 정밀 필터 단축키를 다시 눌러도 필터는 유지한다. 전체 보기 복귀는 `Option + Command + A`만 담당한다.

## 기존 단축키와의 구분

- 보조 키가 없는 `1–5`는 현재 선택한 JPG에 별점을 지정한다.
- 보조 키가 없는 `0`은 별점만 해제한다.
- 보조 키가 없는 `6–9`는 현재 선택한 JPG에 컬러 레이블을 지정하거나 같은 컬러를 해제한다.
- `Option + Command`가 함께 눌린 경우에는 레이블 값을 변경하지 않고 보기 필터만 변경한다.
- 입력창, 텍스트 영역과 편집 가능한 요소에서는 기존처럼 사진 단축키를 실행하지 않는다.

## 필터 동작

- 정밀 필터는 JPG에만 적용한다. RAW와 사이드카에는 별점·컬러 레이블이 없으므로 정밀 필터 결과에서 제외한다.
- 정밀 필터를 켜면 기존 파일 종류 필터보다 우선한다.
- 왼쪽의 기존 파일 필터를 직접 누르면 정밀 필터를 해제하고 해당 기존 필터를 적용한다.
- 전체화면 미리보기에서 정밀 필터 단축키를 누르면 미리보기를 닫고 썸네일 목록으로 돌아와 결과를 보여준다.
- 필터 결과가 0장이면 기존 빈 상태 문구를 그대로 사용한다.
- 레이블을 수정해 현재 정밀 필터 조건에서 벗어난 사진은 결과 목록에서 즉시 사라진다.

## 화면 표시

- 왼쪽 파일 필터 목록에 별점 1–5와 컬러 4개를 추가하지 않는다. 목록이 불필요하게 길어지는 것을 막는다.
- 하단 단축키 안내에 `⌥⌘1–5 별점만 · ⌥⌘6–9 컬러만 · ⌥⌘A 전체`를 표시한다.
- 정밀 필터가 활성화된 동안 하단에 `필터: 별점 N` 또는 `필터: 컬러명`을 표시한다.
- 기존 `별점`, `레이블 있음`, `제외` 필터와 레이블 개수 표시는 유지한다.
- 새 탭, 팝업, 채운 실행 버튼은 추가하지 않는다.

## 코드 구조

- `lib/photo-bridge/labels.ts`에 정밀 필터 타입과 다음 순수 함수를 둔다.
  - 단축키 숫자를 별점 또는 컬러 필터로 변환
  - 사진이 정밀 필터와 일치하는지 판정
  - 화면에 표시할 필터 이름 생성
- `OliviaBridgeWorkspace.tsx`는 정밀 필터 상태를 보관하고 키 입력, 기존 필터 클릭, 전체화면 종료를 연결한다.
- 레이블 저장 형식은 바꾸지 않는다. 정밀 필터는 보기 상태이므로 localStorage에 저장하지 않고 Bridge 창을 다시 열면 전체 보기로 시작한다.

## 오류와 안전

- 이 기능은 브라우저 안에서 목록만 거른다. 파일 이동, 이름 변경, 삭제 또는 NAS 작업을 실행하지 않는다.
- 브라우저나 운영체제가 예약한 조합과 충돌하지 않도록 처리한 키 이벤트에서만 기본 동작을 막는다.
- `Option + Command` 외에 `Control`, `Shift`가 추가로 눌린 조합은 정밀 필터로 처리하지 않는다.

## 테스트

- `Option + Command + 1–5`가 정확히 같은 별점만 보여준다.
- `Option + Command + 6–9`가 정확히 같은 컬러만 보여준다.
- 별점과 컬러가 동시에 있는 사진은 각 해당 필터에서 모두 보인다.
- `Option + Command + A`가 정밀 필터를 해제하고 모든 파일 보기로 돌아간다.
- 보조 키 없는 숫자 단축키는 기존 레이블 지정 동작을 유지한다.
- 기존 파일 필터를 클릭하면 정밀 필터가 해제된다.
- 전체화면에서 정밀 필터를 적용하면 전체화면이 닫히고 필터 결과가 보인다.
- 타입 검사, lint, Bridge 관련 Vitest, 전체 Vitest와 build를 실행한다.

## 자체 검토

- 미정 항목이나 자리표시자가 없다.
- 숫자 단축키의 지정 동작과 필터 동작이 보조 키 유무로 명확히 분리된다.
- 기존 레이블 저장 형식, 파일 작업 기능, 팝업과 레이아웃은 변경하지 않는다.
- 범위는 Olivia Bridge의 레이블 보기 필터에 한정한다.
