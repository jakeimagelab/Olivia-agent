# GEO 레이더 1차 설계

## 목표

기존 AI Trust Gap의 데이터와 갭·전략·촬영 계획 기능을 보존하면서, 지역 안에서 실제 웹 검색 기반 AI가 어떤 병원을 추천하는지 반복 측정하는 독립 Olivia OS 앱으로 재구성한다.

## 확정된 운영 원칙

- 운영 Supabase에는 코드가 직접 쓰지 않는다.
- 기존 `supabase/ai-trust-gap-schema.sql`을 먼저 적용하고, 새 `supabase/geo-radar-v1.sql`을 다음에 적용한다.
- 글로리의원은 별도의 실행 가능한 등록 SQL 예시로만 제공한다.
- API 키가 없는 Provider와 카카오맵은 `키 없음` 상태로 비활성화한다.
- 외부 웹사이트 화면 자동화나 병원 홈페이지 크롤링은 하지 않는다.
- 측정 API는 공식 웹 검색 도구만 사용하고 모델명·예산·단가는 환경변수와 설정 테이블에서 읽는다.

## 선택한 구조

### 1. 독립 앱과 호환 라우트

- `/geo-radar`가 정식 앱 화면이다.
- `/ai-trust-gap`은 쿼리스트링을 보존해 `/geo-radar`로 리다이렉트한다.
- Olivia OS registry에는 singleton 창으로 등록하고 `AnalysisHostProvider surface="window"` 안에서 동일 화면을 사용한다.
- 브랜드 진단센터의 하위 도구에서는 제거하되 기존 검색 별칭은 유지한다.

### 2. 영속 작업 대기열

동기 요청 안에서 전체 측정을 처리하지 않는다. 측정 시작 API는 실행과 `ai_query` 작업을 생성한 뒤 즉시 반환한다. `/api/cron/ai-trust-worker`가 임대 잠금 방식으로 제한된 수의 작업을 처리한다.

- 잠금 만료: 10분
- 재시도: 1분, 5분, 30분
- 최대 시도: 3회
- 작업 종류: `ai_query`, `clinic_sync`, `extract`, `score`
- 같은 실행·질문·Provider·반복 번호의 중복 작업은 idempotency key로 차단한다.

이 구조는 창을 닫거나 다른 Olivia OS 앱으로 이동해도 서버 작업이 지속되고, UI는 실행 상태를 폴링해 복원한다.

### 3. Provider 어댑터

- OpenAI: Responses API의 `web_search` 도구와 서울 사용자 위치.
- Gemini: `google_search` grounding 도구.
- Anthropic: Messages API의 서버 웹 검색 도구와 사용자 위치.
- Perplexity: 2026년 9월 종료된 Sonar Chat Completions 대신 현재 공식 Agent API. Provider 이름은 기존 호환을 위해 `perplexity`를 유지한다.

응답은 공통 형태로 정규화한다: 실제 모델명, 원문, 인용, 출처 URL, 입력·출력 토큰, 웹 검색 횟수, 요청 파라미터. 비밀 키와 개인정보는 저장하거나 로그에 남기지 않는다.

### 4. 지역과 병원 목록

- 반경, 구 묶음, 도시, 직접 지정 범위를 `ai_trust_regions`에 저장한다.
- 기본 프리셋은 언주역 1km, 강남권, 서울이다.
- 병원 목록은 HIRA 병원기본목록을 우선하고 카카오 로컬을 보완 소스로 사용한다.
- 중복은 정규화 이름·주소·전화 조합으로 병합하며 자동 확신이 낮은 AI 언급은 검수 대기함으로 보낸다.
- 병원 홈페이지는 API에 포함된 값만 사용하며 이번 단계에서는 사이트를 크롤링하지 않는다.

### 5. 비용과 안전장치

- 호출마다 `ai_trust_cost_ledger`에 Provider, 실제 모델, 토큰, 검색 횟수, 단가, 금액을 기록한다.
- `ai_trust_settings` 기본값은 프로젝트 월 20달러, 전체 월 100달러다.
- 80%에서 경고하고 100%에서 신규 작업을 중단한다.
- AI API와 GEO 레이더 API는 관리자 세션만 접근할 수 있다.
- 원문은 180일 후 정리하되 집계 데이터는 유지한다.

### 6. UI 상태

UI는 시안의 정보 구조와 Olivia OS 밝은 세이지 디자인 토큰을 사용한다.

- 새 분석: 범위·병원 → 질문 확인 → 실행 → 결과
- 결과: AI 추천 순위, 지도, 사이트 점수(2차 안내), 갭·전략·촬영 계획, 추이, 보고서
- 운영 화면: 대기·실행·실패 작업과 비용
- 스키마 미적용, 키 누락, 지도 키 누락은 각각 복구 방법이 있는 명시적 상태로 표시한다.
- 1024px 미만에서는 사이드바를 접고 카드를 한 열로 배치한다.

## 검증 경계

- 운영 DB 미적용 상태에서는 타입 검사·빌드·순수 함수/API 계약·UI fallback을 검증한다.
- 실제 병원 수집, 실제 측정, 비용 장부, 지도 핀 스크린샷은 사용자가 두 SQL을 적용하고 필요한 키를 설정한 뒤 실행 검증한다.
- 키가 연결된 Provider만 실행 수와 비용 계산에 포함한다.
