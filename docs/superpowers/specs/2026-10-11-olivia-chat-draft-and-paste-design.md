# Olivia 채팅 초안 보존과 붙여넣기 설계

## 목표

Olivia 채팅에 전송하지 않은 글을 브라우저 종료·새로고침 뒤에도 복원하고, 미전송 글이 있는 상태에서 페이지를 떠날 때 Chrome 기본 경고를 표시한다. 다른 메모 앱에서 붙여넣은 글은 문단·줄바꿈·빈 줄을 원문 그대로 유지한다.

## 범위

- 채팅 입력 텍스트의 브라우저 로컬 임시 저장과 자동 복원
- 미전송 텍스트가 있을 때 `beforeunload` 기본 경고 표시
- 일반 텍스트와 HTML 클립보드의 줄바꿈 보존
- 전송 및 새 대화 시작 시 저장된 초안 삭제
- 관련 단위·컴포넌트 테스트 추가

첨부 파일 임시 저장, 서버·Supabase 저장, 여러 기기 사이 초안 동기화는 포함하지 않는다.

## 저장 방식

- 메시지 캐시와 분리된 버전 키 `olivia:conversation-draft:v1`을 사용한다.
- 값은 가공하지 않은 입력 문자열 그대로 저장해 줄바꿈과 빈 줄을 보존한다.
- 입력 변경 시 브라우저 `localStorage`에 저장하고, 앱 시작 시 한 번 복원한다.
- 공백만 있는 값은 유효한 초안으로 취급하지 않고 저장 키를 제거한다.
- 전송을 시작하거나 새 대화를 시작하면 메모리의 입력값과 저장 키를 함께 비운다.
- 작업실 이동, 채팅 최소화, 패널 닫기는 초안을 지우지 않는다.
- 저장소 접근이 차단된 브라우저에서도 채팅이 멈추지 않도록 저장·복원 오류는 안전하게 무시한다.

## 종료 경고

- `input.trim()`이 비어 있지 않을 때만 `beforeunload` 리스너를 활성화한다.
- 리스너는 `event.preventDefault()`와 `event.returnValue = ""`를 설정해 브라우저 기본 경고를 요청한다.
- 경고 문구는 Chrome이 결정하므로 앱에서 별도 문구를 지정하지 않는다.
- 새로고침, 탭 닫기, Chrome 창 닫기, 외부 주소 이동에는 경고가 적용된다.
- 앱 내부 화면 이동, 채팅 최소화·닫기에는 경고를 띄우지 않고 저장된 초안을 유지한다.

## 붙여넣기와 줄바꿈

- 붙여넣기 시 클립보드의 `text/plain`을 우선 사용한다.
- `CRLF`, `CR`, Unicode 줄 구분자(`U+2028`, `U+2029`)를 `LF`로 통일하되 연속 줄바꿈은 줄이지 않는다.
- 일반 텍스트에 실제 줄바꿈이 없고 `text/html`에 문단 구조가 있으면 `br`, `p`, `div`, `li`, 제목 요소의 경계를 줄바꿈으로 변환한다.
- 목록 항목의 텍스트·기호와 문단 사이 빈 줄은 가능한 한 유지한다.
- 정규화한 텍스트는 현재 커서 또는 선택 범위에 삽입한다. 기존 입력 전체를 덮어쓰지 않는다.
- 전송 시에도 저장된 문자열의 내부 줄바꿈을 유지한다. 기존 전송 전후의 바깥 공백 처리만 유지한다.

## 컴포넌트 경계

- 초안 저장·복원·삭제는 Conversation Store 주변의 작은 저장 유틸리티가 담당한다.
- `OliviaConversation`은 종료 경고 생명주기와 textarea 붙여넣기 이벤트를 담당한다.
- 클립보드 텍스트 정규화는 DOM 이벤트와 분리된 순수 함수로 만들어 직접 테스트한다.
- 기존 메시지 캐시, 전송 API, 첨부 파일 처리, 채팅 UI 모양은 변경하지 않는다.

## 오류와 복구

- `localStorage`를 읽거나 쓸 수 없어도 현재 세션 입력은 계속 동작한다.
- HTML 파싱에 실패하면 `text/plain`을 그대로 사용한다.
- 클립보드에 사용할 수 있는 텍스트가 없으면 브라우저의 기본 붙여넣기 동작을 막지 않는다.

## 검증

- 여러 줄과 빈 줄이 포함된 초안을 저장한 뒤 새 Store에서 정확히 복원되는지 확인한다.
- 전송 및 새 대화 시작 뒤 저장 키가 제거되는지 확인한다.
- 공백뿐인 입력은 종료 경고를 만들지 않는지 확인한다.
- 실제 텍스트가 있을 때만 `beforeunload`가 기본 경고를 요청하는지 확인한다.
- CRLF·Unicode 줄 구분자가 LF로 바뀌면서 빈 줄은 유지되는지 확인한다.
- 한 줄로 뭉친 일반 텍스트와 문단형 HTML이 함께 있을 때 HTML 문단을 줄바꿈으로 복원하는지 확인한다.
- 붙여넣기가 선택 범위에 삽입되고 앞뒤 기존 텍스트를 보존하는지 확인한다.
- 기존 Conversation Store 및 작업실 전환 초안 유지 테스트가 계속 통과하는지 확인한다.
- TypeScript 검사와 변경 파일 lint를 실행한다.

## 제외 사항

- 초안의 Supabase 저장 및 계정 간 동기화
- 첨부 이미지·파일의 브라우저 재실행 후 복원
- 브라우저 종료 경고의 사용자 정의 문구
- 기존 채팅 화면의 색·레이아웃·버튼 변경
