# 브릿지 전체 선택과 기본 도구 활성화 설계

## 목표

- 브릿지 파일 영역에서 `Command+A`(Windows에서는 `Ctrl+A`)를 누르면 현재 필터를 통과해 화면에 보이는 JPG를 모두 선택한다.
- 폴더 스캔이 끝나 JPG가 보이면, 사용자가 사진을 따로 선택하지 않아도 하단 작업 도구를 사용할 수 있다.
- 선택이 없는 상태에서 도구를 누르면 현재 보이는 JPG 전체를 그 도구의 입력으로 확정한다.

## 동작 범위

- 전체 선택과 기본 입력 대상은 `visibleJpgs`로 한정한다.
- `하위 폴더 JPG 포함`, 파일 필터, 별점·컬러 필터 결과를 그대로 반영한다.
- RAW와 사이드카는 대상에 넣지 않는다.
- 사용자가 일부 JPG를 직접 선택한 경우에는 기존처럼 그 선택만 사용한다.

## 구현

1. 브릿지 키보드 핸들러에서 입력창이 아닌 경우 `Command/Ctrl+A`를 가로채 `visibleJpgs`의 ID 전체를 선택한다.
2. 도구 비활성 조건을 `선택 0장`이 아니라 `현재 보이는 JPG 0장`으로 바꾼다.
3. 선택 0장인 상태에서 도구를 열 때 `visibleJpgs` 전체를 먼저 선택 상태와 사진 작업 저장소에 반영한 뒤 기존 도구 흐름을 그대로 연다.
4. 하단 단축키 안내를 `⌘/Ctrl+A 전체 선택`으로 고친다.

## 보존 사항

- 파일 읽기, 이동, 삭제, 원격 작업 API는 바꾸지 않는다.
- 별점·컬러·제외 기능의 현재 선택 처리 방식은 바꾸지 않는다.
- 원격 NAS에서 로컬 전용 도구가 비활성화되는 기존 제한은 유지한다.
- 레이아웃, 색, 크기와 도구 배치는 바꾸지 않는다.

## 확인

- 필터가 없는 상태와 필터가 있는 상태에서 `Command/Ctrl+A`가 보이는 JPG만 선택하는지 확인한다.
- 선택 0장이어도 JPG가 보이면 하단 도구가 활성화되는지 확인한다.
- 도구를 누르면 보이는 JPG 전체가 입력으로 전달되는지 확인한다.
- JPG가 없거나 스캔 전이면 기존처럼 비활성화되는지 확인한다.
- 타입 검사와 관련 테스트를 실행한다.
